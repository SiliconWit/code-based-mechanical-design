A bolt model downloaded from the web looks right until the real bolt arrives: the head is 1 mm wider than the model, and it no longer fits the pocket you designed for it. Fasteners are made to published standards, so their sizes do not need to be guessed or downloaded. In this lesson you type the standard tables into Python once and write four short functions that build hex bolts, socket cap screws, nuts and washers from them with CadQuery, a Python library that makes solid models from code. One run then writes more than 250 model files you can reuse in every project. #CadQuery #ISOFasteners #ParametricCAD

## Learning Objectives

By the end of this lesson, you will be able to:

1. Set up CadQuery with Jupyter and OCP CAD Viewer for interactive 3D development
2. Translate ISO standards tables into Python dictionaries for parametric design
3. Generate helical thread geometry from ISO metric thread equations
4. Build parametric functions for hex bolts, socket cap screws, nuts, and washers
5. Export a batch library of 50+ standard parts as STEP and STL files
6. Validate generated dimensions against ISO specifications

## ISO Standards Reference

<InArticleAd />


A bolt from one factory fits a nut from another because both are made to the same published table. ISO, the International Organization for Standardization, publishes one document for each fastener type. Each lists every dimension for every size. A size such as M8 names the outside diameter of the thread in millimetres, not the size of the wrench.

```text
        head              shank             thread
      ┌──────┐
      │      ├────────────────┬╱╲╱╲╱╲╱╲╱╲╱╲╱╲┐  ▲
    s │      │                │              │  d
      │      ├────────────────┴╲╱╲╱╲╱╲╱╲╱╲╱╲╱┘  ▼
      └──────┘                   ►│ │◄ P
      ◄─ k ─►◄─────────── l ────────────────►
                              ◄───── b ──────►
```

- $d$ = nominal diameter, the outside diameter of the thread (8 mm for M8)
- $P$ = pitch, the distance from one thread crest to the next
- $s$ = width across flats, the wrench size
- $k$ = head height
- $l$ = length, measured from under the head
- $b$ = threaded length

### ISO Metric Thread Dimensions (ISO 261 / ISO 724)

A thread is a ridge with a V-shaped section, wound around a cylinder. Two numbers define an ISO metric thread: the nominal diameter $d$ and the pitch $P$. The table uses the coarse pitch, the standard one for each size. Three diameters follow from them:

- the major diameter, over the crests, equal to $d$
- the minor diameter $d_3$, at the bottom of the grooves. The bolt breaks here, so strength is calculated from it.
- the pitch diameter $d_2$, between the two, where ridge and groove are equally wide. It decides how bolt and nut fit.

| Size | Nominal Diameter $d$ (mm) | Coarse Pitch $P$ (mm) | Minor Diameter $d_3$ (mm) | Pitch Diameter $d_2$ (mm) |
|------|--------------------------|----------------------|--------------------------|--------------------------|
| M3   | 3.000  | 0.500 | 2.387 | 2.675 |
| M4   | 4.000  | 0.700 | 3.141 | 3.545 |
| M5   | 5.000  | 0.800 | 4.019 | 4.480 |
| M6   | 6.000  | 1.000 | 4.773 | 5.350 |
| M8   | 8.000  | 1.250 | 6.466 | 7.188 |
| M10  | 10.000 | 1.500 | 8.160 | 9.026 |
| M12  | 12.000 | 1.750 | 9.853 | 10.863 |
| M14  | 14.000 | 2.000 | 11.546 | 12.701 |
| M16  | 16.000 | 2.000 | 13.546 | 14.701 |
| M20  | 20.000 | 2.500 | 16.933 | 18.376 |

The thread form itself is fixed by ISO 68-1. Its flanks meet at 60 degrees, so a sharp V of pitch $P$ would have the height:

$$H = \frac{\sqrt{3}}{2} \cdot P$$

with $H$ and $P$ in mm. The real thread is this V with its tip and its bottom cut off, and the two diameters are fixed fractions of the pitch below $d$:

$$d_2 = d - 0.6495 \cdot P$$

$$d_3 = d - 1.2269 \cdot P$$

For M8, $d_3 = 8 - 1.2269 \times 1.25 = 6.466$ mm, as in the table.

## Thread Generation

<InArticleAd />


The thread is the hardest shape in a fastener, because its ridge climbs around the axis as a helix, the curve of a spiral staircase.

### Thread Profile Geometry

The profile is the sharp V of height $H \approx 0.8660 \cdot P$ with material removed at both ends. On a bolt, $\frac{H}{8}$ is cut from the tip (the crest) and $\frac{H}{4}$ from the bottom of the groove (the root). What is left is the basic thread height, the depth over which bolt and nut overlap:

$$H_1 = \frac{5}{8} \cdot H = \frac{5\sqrt{3}}{16} \cdot P \approx 0.5413 \cdot P$$

The code uses this basic profile, which gives a minor diameter of $d - 1.0825 \cdot P$. A real bolt has a rounded root cut a little deeper, $h_3 = \frac{17}{24} \cdot H \approx 0.6134 \cdot P$, and that depth is behind the $d_3$ column in the table. So the model is slightly thicker at the root than a real bolt: 6.65 mm against 6.47 mm for M8.

### Helical Thread Function

The function draws one cross-section of the threaded rod, cut at a right angle to the axis. It is nearly a circle, with a radius that changes from the minor to the major radius once around. It then extrudes this shape along the axis while turning it one full turn for each pitch. The result is one solid, which is more reliable than winding a ridge onto a cylinder and joining the two.

```python
def make_thread(diameter, pitch, length, external=True):
    """
    Generate an ISO metric thread as one solid, using a twisted extrusion.

    Parameters:
        diameter (float): Nominal diameter in mm (e.g., 6.0 for M6)
        pitch (float): Thread pitch in mm (e.g., 1.0 for M6 coarse)
        length (float): Thread length in mm
        external (bool): True for bolt thread, False for nut thread

    Returns:
        cq.Workplane: CadQuery solid of the threaded cylinder
    """
    # Fundamental triangle height (ISO 68-1)
    H = (math.sqrt(3) / 2.0) * pitch

    # Basic profile: thread depth is 5/8 of H for bolt and nut
    thread_depth = (5/8) * H
    d_major = diameter
    d_minor = diameter - 2 * thread_depth

    # Number of full turns
    n_turns = length / pitch

    # Cross-section of a single-start thread, cut at a right angle
    # to the axis. Moving once around the axis (360 degrees) is the
    # same as moving one pitch along it, so the axial profile
    #   root flat (P/4) -> flank (5P/16) -> crest flat (P/8) -> flank (5P/16)
    # becomes a radius that changes with angle.
    r_minor = d_minor / 2.0
    r_major = d_major / 2.0
    root_flat = pitch / 4.0
    crest_flat = pitch / 8.0
    flank = (pitch - root_flat - crest_flat) / 2.0   # 5P/16, gives 30-degree flanks

    def radius_at(z):
        """Thread radius at axial position z within one pitch."""
        if z < root_flat:
            return r_minor
        if z < root_flat + flank:
            return r_minor + thread_depth * (z - root_flat) / flank
        if z < root_flat + flank + crest_flat:
            return r_major
        return r_major - thread_depth * (z - root_flat - flank - crest_flat) / flank

    n_pts = 96  # points around the cross-section
    section_pts = []
    for i in range(n_pts):
        angle = 2 * math.pi * i / n_pts
        r = radius_at(pitch * i / n_pts)
        section_pts.append((r * math.cos(angle), r * math.sin(angle)))

    # Twist the cross-section by one full turn per pitch
    thread_solid = (
        cq.Workplane("XY")
        .polyline(section_pts)
        .close()
        .twistExtrude(length, 360.0 * n_turns)
    )

    if external:
        return thread_solid

    # For internal, return a hollow cylinder with the thread cut into its bore
    body = (
        cq.Workplane("XY")
        .circle(d_major / 2.0 + 1.0)  # outer wall
        .extrude(length)
    )
    return body.cut(thread_solid)
```

:::caution[Thread Simplification]
A true helical thread is slow to compute and gives large files. Model it only when the thread itself will be made from the model, as in 3D printing. A purchased bolt in an assembly needs only the right outside sizes.
:::

### Simplified Thread (Cosmetic)

A cosmetic thread only looks like a thread. The function makes a plain cylinder of the nominal diameter and cuts a shallow ring groove at each pitch, down to the minor diameter. The grooves are rings, not a helix, so this part cannot be screwed into anything.

```python
def make_cosmetic_thread(diameter, pitch, length, external=True):
    """
    Generate a simplified cosmetic thread representation.
    Uses concentric cylinders at major and minor diameters.
    Much faster than helical sweep; sufficient for assembly visualization.
    """
    H = (math.sqrt(3) / 2.0) * pitch
    d_minor = diameter - 2 * (5/8) * H

    if external:
        # Bolt: cylinder at minor diameter with thread indicator rings
        thread = (
            cq.Workplane("XY")
            .circle(diameter / 2.0)
            .extrude(length)
        )
        # Add visual thread indicator: grooves at pitch intervals
        n_grooves = int(length / pitch)
        for i in range(n_grooves):
            z = i * pitch + pitch / 2.0
            groove = (
                cq.Workplane("XY")
                .workplane(offset=z)
                .circle(diameter / 2.0)
                .circle(d_minor / 2.0)
                .extrude(pitch * 0.1)
            )
            thread = thread.cut(groove)
        return thread
    else:
        # Nut: bore at minor diameter
        return (
            cq.Workplane("XY")
            .circle(diameter / 2.0 + 2.0)
            .circle(d_minor / 2.0)
            .extrude(length)
        )
```

## Hex Bolt: `make_hex_bolt()`

<InArticleAd />

The function looks up the size in the tables and joins three solids: a six-sided head, a plain shank and a thread. The length you pass is measured from under the head, as on a bolt you buy, so an M8x40 is 45.3 mm long over all. The thread takes the standard length $b$ and the shank takes the rest. The validation tab measures the finished solid and compares it with the table.

<Tabs>
  <TabItem label="Function Code">

```python
def make_hex_bolt(size, length, thread_type="cosmetic"):
    """
    Generate an ISO 4014 hex bolt.

    Parameters:
        size (str): Bolt size, e.g. "M6", "M10"
        length (float): Total bolt length in mm (shank + thread)
        thread_type (str): "cosmetic" for fast, "helical" for detailed

    Returns:
        cq.Workplane: Complete hex bolt solid
    """
    # Look up ISO dimensions
    td = THREAD_DATA[size]
    hd = HEX_BOLT_DATA[size]
    d = td["d"]       # nominal diameter
    P = td["P"]       # thread pitch
    s = hd["s"]       # across-flats width
    k = hd["k"]       # head height
    b = hd["b"]       # thread length (ISO default)

    # Calculate derived dimensions
    e = s / math.cos(math.radians(30))  # across-corners width
    thread_len = min(b, length)          # actual thread length
    shank_len = max(0, length - thread_len)

    # ─── Head: hexagonal prism with chamfered edges ───
    head = (
        cq.Workplane("XY")
        .polygon(6, e)               # regular hexagon, across-corners
        .extrude(k)
        .edges(">Z")
        .chamfer(k * 0.15)          # top chamfer (first, while the top edges are long)
        .edges("|Z")
        .chamfer(0.5)                # edge chamfer
    )

    # ─── Shank: unthreaded cylindrical section ───
    if shank_len > 0:
        shank = (
            cq.Workplane("XY")
            .workplane(offset=-shank_len)
            .circle(d / 2.0)
            .extrude(shank_len)
        )
    else:
        shank = cq.Workplane("XY")  # empty

    # ─── Threaded section ───
    thread_start_z = -shank_len - thread_len
    if thread_type == "helical":
        thread = make_thread(d, P, thread_len, external=True)
    else:
        thread = make_cosmetic_thread(d, P, thread_len, external=True)

    # Move thread to correct position
    thread = thread.translate((0, 0, thread_start_z))

    # ─── Thread tip: 45-degree chamfer on the end ───
    chamfer_height = d * 0.3
    tip_cone = cq.Solid.makeCone(d / 2.0, 0, chamfer_height).moved(
        cq.Location(cq.Vector(0, 0, thread_start_z - chamfer_height))
    )

    # ─── Assembly ───
    bolt = head
    if shank_len > 0:
        bolt = bolt.union(shank)
    bolt = bolt.union(thread)

    return bolt
```

## Socket Head Cap Screw: `make_socket_cap()`

<InArticleAd />

A socket cap screw has a round head with a six-sided hole for a hex key, so it fits where a wrench cannot reach. The function builds the head as a cylinder, cuts the hex hole into it, and adds shank and thread as before.

<Tabs>
  <TabItem label="Function Code">

```python
def make_socket_cap(size, length, thread_type="cosmetic"):
    """
    Generate an ISO 4762 socket head cap screw.

    Parameters:
        size (str): Screw size, e.g. "M5", "M8"
        length (float): Screw length in mm (below head)
        thread_type (str): "cosmetic" or "helical"

    Returns:
        cq.Workplane: Complete socket cap screw solid
    """
    td = THREAD_DATA[size]
    sd = SOCKET_CAP_DATA[size]
    d = td["d"]
    P = td["P"]
    dk = sd["dk"]         # head diameter
    k = sd["k"]           # head height
    s_hex = sd["s_hex"]   # hex socket size (across flats)

    # Socket depth is typically 60% of head height
    socket_depth = k * 0.6

    # ─── Head: cylindrical with hex socket ───
    head = (
        cq.Workplane("XY")
        .circle(dk / 2.0)
        .extrude(k)
        .edges(">Z")
        .chamfer(0.3)
    )

    # Cut the hex socket into the top of the head
    hex_across_corners = s_hex / math.cos(math.radians(30))
    socket_cut = (
        cq.Workplane("XY")
        .workplane(offset=k - socket_depth)
        .polygon(6, hex_across_corners)
        .extrude(socket_depth + 0.1)  # slight overshoot for clean cut
    )
    head = head.cut(socket_cut)

    # ─── Body: determine shank vs thread split ───
    # ISO 4762: thread length b = 2d + 6 for l <= 125mm
    b = 2 * d + 6
    thread_len = min(b, length)
    shank_len = max(0, length - thread_len)

    # ─── Shank ───
    if shank_len > 0:
        shank = (
            cq.Workplane("XY")
            .workplane(offset=-shank_len)
            .circle(d / 2.0)
            .extrude(shank_len)
        )
    else:
        shank = None

    # ─── Threaded portion ───
    if thread_type == "helical":
        thread = make_thread(d, P, thread_len, external=True)
    else:
        thread = make_cosmetic_thread(d, P, thread_len, external=True)
    thread = thread.translate((0, 0, -shank_len - thread_len))

    # ─── Chamfered tip ───
    # Standard 45-degree chamfer at the screw tip

    # ─── Combine ───
    screw = head
    if shank is not None:
        screw = screw.union(shank)
    screw = screw.union(thread)

    return screw
```

**Socket cap screws vs hex bolts:**

| Feature | Hex Bolt (ISO 4014) | Socket Cap (ISO 4762) |
|---------|--------------------|-----------------------|
| Head shape | Hexagonal prism | Cylinder with hex socket |
| Drive type | External hex (wrench) | Internal hex (Allen key) |
| Head height | Lower profile | Taller for given size |
| Typical use | General-purpose | Tight spaces, higher torque |
| Thread length for $l \leq 125$ mm | $b = 2d + 6$ (the table) | $b = 2d + 12$ in the standard. The code uses $2d + 6$. |

The hex socket is modeled by cutting a regular hexagon into the cylindrical head. The socket size $s$ is the across-flats dimension (the Allen key size you would use). The across-corners dimension for the cut is:

$$e_{socket} = \frac{s}{\cos(30°)} = \frac{2s}{\sqrt{3}}$$

## Hex Nut: `make_nut()`

<InArticleAd />

The function builds a six-sided block from the width across flats $s$ and the height $m$, cuts the hole, and widens both ends of it so that a bolt enters easily. It computes the width across corners as $s / \cos 30°$, for sharp corners. The table lists a smaller $e$, the minimum allowed, because real nuts have their corners cut off.

<Tabs>
  <TabItem label="Function Code">

```python
def make_nut(size, thread_type="cosmetic"):
    """
    Generate an ISO 4032 hex nut (Style 1).

    Parameters:
        size (str): Nut size, e.g. "M6", "M10"
        thread_type (str): "cosmetic" or "helical"

    Returns:
        cq.Workplane: Complete hex nut solid
    """
    td = THREAD_DATA[size]
    nd = HEX_NUT_DATA[size]
    d = td["d"]
    P = td["P"]
    s = nd["s"]    # across-flats
    m = nd["m"]    # nut height

    # Calculate across-corners from across-flats
    e = s / math.cos(math.radians(30))

    # Derived thread dimensions
    H = (math.sqrt(3) / 2.0) * P
    d_minor = d - 2 * (5/8) * H

    # ─── Outer body: hexagonal prism ───
    body = (
        cq.Workplane("XY")
        .polygon(6, e)
        .extrude(m)
        .edges(">Z or <Z")
        .chamfer(m * 0.1)            # top and bottom chamfer first
        .edges("|Z")
        .chamfer(0.4)
    )

    # ─── Internal thread bore ───
    if thread_type == "helical":
        # Cutting the bolt-shaped thread solid out of the body
        # leaves the matching internal thread
        bore = make_thread(d, P, m, external=True)
    else:
        # Cosmetic: simple bore at minor diameter
        bore = (
            cq.Workplane("XY")
            .circle(d / 2.0)      # clearance at nominal diameter
            .extrude(m)
        )

    # Cut the bore from the hex body
    nut = body.cut(bore)

    # ─── Chamfer the bore entries (both sides) ───
    # 30-degree lead-in chamfer for thread engagement
    chamfer_depth = P * 0.8
    top_chamfer = (
        cq.Workplane("XY")
        .workplane(offset=m - chamfer_depth)
        .circle(d / 2.0 + chamfer_depth)
        .workplane(offset=chamfer_depth)
        .circle(d / 2.0)
        .loft()
    )
    bottom_chamfer = (
        cq.Workplane("XY")
        .circle(d / 2.0)
        .workplane(offset=chamfer_depth)
        .circle(d / 2.0 + chamfer_depth)
        .loft()
    )

    # These lofted shapes remove material to create the chamfered entry
    nut = nut.cut(top_chamfer).cut(bottom_chamfer)

    return nut
```

## Flat Washer: `make_washer()`

<InArticleAd />

A washer is a flat ring that spreads the clamping force of the bolt over a wider area. Its hole is a little larger than the bolt: 8.4 mm for M8.

<Tabs>
  <TabItem label="Function Code">

```python
def make_washer(size):
    """
    Generate an ISO 7089 flat washer (normal series).

    Parameters:
        size (str): Washer size, e.g. "M6", "M10"

    Returns:
        cq.Workplane: Complete flat washer solid
    """
    wd = WASHER_DATA[size]
    d1 = wd["d1"]   # inner diameter
    d2 = wd["d2"]   # outer diameter
    h = wd["h"]     # thickness

    # Create the washer as an annular disc
    washer = (
        cq.Workplane("XY")
        .circle(d2 / 2.0)
        .circle(d1 / 2.0)
        .extrude(h)
    )

    # Optional: add a small edge break (0.1 mm chamfer)
    # This improves printability and matches real washers
    try:
        washer = washer.edges().chamfer(min(0.1, h * 0.1))
    except Exception:
        pass  # very thin washers may not support chamfer

    return washer
```

## Fastener Assembly Example

<InArticleAd />


The four functions together give a bolted joint. The function below builds each part, then moves it along the Z axis to its place: washer and bolt head above the plate, washer and nut below it.

```python
from ocp_vscode import show

def make_bolted_joint(size, bolt_length, grip_thickness):
    """
    Assemble a complete bolted joint:
    washer + bolt through a plate, washer + nut on the other side.

    Parameters:
        size (str): Fastener size (e.g., "M8")
        bolt_length (float): Bolt length in mm
        grip_thickness (float): Total plate thickness in mm
    """
    td = THREAD_DATA[size]
    hd = HEX_BOLT_DATA[size]
    wd = WASHER_DATA[size]
    nd = HEX_NUT_DATA[size]

    # Generate components
    bolt = make_hex_bolt(size, bolt_length)
    nut = make_nut(size)
    washer_top = make_washer(size)
    washer_bottom = make_washer(size)

    # Plate with clearance hole
    clearance_dia = td["d"] + 1.0  # 1mm clearance
    plate = (
        cq.Workplane("XY")
        .box(wd["d2"] * 3, wd["d2"] * 3, grip_thickness)
        .faces(">Z")
        .workplane()
        .hole(clearance_dia)
    )

    # Position everything along the Z axis
    # Bolt head sits on top washer, on top of plate
    z_plate_top = grip_thickness / 2.0
    z_plate_bottom = -grip_thickness / 2.0

    # Top washer sits on plate surface
    washer_top = washer_top.translate((0, 0, z_plate_top))

    # Bolt head sits on top of washer
    bolt_z = z_plate_top + wd["h"]
    bolt = bolt.translate((0, 0, bolt_z))

    # Bottom washer under the plate
    washer_bottom = washer_bottom.translate(
        (0, 0, z_plate_bottom - wd["h"])
    )

    # Nut under the bottom washer
    nut_z = z_plate_bottom - wd["h"] - nd["m"]
    nut = nut.translate((0, 0, nut_z))

    return bolt, washer_top, plate, washer_bottom, nut

# Create an M8 bolted joint through a 10mm plate
components = make_bolted_joint("M8", 35, 10)
show(*components)
```

## Batch Library Generation

<InArticleAd />


The script below builds the whole library in one run: every size of every type, as STEP and as STL. A length shorter than 1.5 times the diameter is skipped, which leaves 56 bolts, 56 screws, 10 nuts and 10 washers: 264 files.

```python
import os
import cadquery as cq

def generate_hardware_library(output_dir="hardware_library"):
    """
    Generate a complete ISO fastener library.

    Creates subdirectories for each fastener type and exports
    every size in both STEP and STL formats.
    """
    # Create output directory structure
    dirs = {
        "bolts": os.path.join(output_dir, "hex_bolts"),
        "screws": os.path.join(output_dir, "socket_cap_screws"),
        "nuts": os.path.join(output_dir, "hex_nuts"),
        "washers": os.path.join(output_dir, "flat_washers"),
    }
    for d in dirs.values():
        os.makedirs(d, exist_ok=True)

    sizes = ["M3", "M4", "M5", "M6", "M8", "M10", "M12", "M14", "M16", "M20"]
    bolt_lengths = [10, 16, 20, 25, 30, 40, 50]  # common lengths in mm

    file_count = 0

    # ─── Hex Bolts: each size × multiple lengths ───
    print("Generating hex bolts...")
    for size in sizes:
        for length in bolt_lengths:
            # Skip unreasonable combinations (e.g., M20x10)
            min_len = HEX_BOLT_DATA[size]["b"]  # minimum = thread length
            if length < THREAD_DATA[size]["d"] * 1.5:
                continue

            name = f"ISO4014_{size}x{length}"
            bolt = make_hex_bolt(size, length)

            cq.exporters.export(bolt, os.path.join(dirs["bolts"], f"{name}.step"))
            cq.exporters.export(bolt, os.path.join(dirs["bolts"], f"{name}.stl"))
            file_count += 2
            print(f"  {name}")

    # ─── Socket Cap Screws: each size × multiple lengths ───
    print("Generating socket cap screws...")
    for size in sizes:
        for length in bolt_lengths:
            if length < THREAD_DATA[size]["d"] * 1.5:
                continue

            name = f"ISO4762_{size}x{length}"
            screw = make_socket_cap(size, length)

            cq.exporters.export(screw, os.path.join(dirs["screws"], f"{name}.step"))
            cq.exporters.export(screw, os.path.join(dirs["screws"], f"{name}.stl"))
            file_count += 2
            print(f"  {name}")

    # ─── Hex Nuts: one per size ───
    print("Generating hex nuts...")
    for size in sizes:
        name = f"ISO4032_{size}"
        nut = make_nut(size)

        cq.exporters.export(nut, os.path.join(dirs["nuts"], f"{name}.step"))
        cq.exporters.export(nut, os.path.join(dirs["nuts"], f"{name}.stl"))
        file_count += 2
        print(f"  {name}")

    # ─── Flat Washers: one per size ───
    print("Generating flat washers...")
    for size in sizes:
        name = f"ISO7089_{size}"
        washer = make_washer(size)

        cq.exporters.export(washer, os.path.join(dirs["washers"], f"{name}.step"))
        cq.exporters.export(washer, os.path.join(dirs["washers"], f"{name}.stl"))
        file_count += 2
        print(f"  {name}")

    print(f"\nLibrary complete: {file_count} files generated in '{output_dir}/'")
    return file_count

# Run the generator
total = generate_hardware_library()
```

### Adding a Countersunk Screw (Exercise)

A countersunk screw has a cone-shaped head that sits level with the surface. The table and a first function are below. Build it and compare the head diameter with the table.

```python
# ISO 10642: Countersunk socket head cap screw
COUNTERSUNK_DATA = {
    "M3":  {"dk": 6.72,  "k": 1.86,  "s_hex": 2.0},
    "M4":  {"dk": 8.96,  "k": 2.48,  "s_hex": 2.5},
    "M5":  {"dk": 11.20, "k": 3.10,  "s_hex": 3.0},
    "M6":  {"dk": 13.44, "k": 3.72,  "s_hex": 4.0},
    "M8":  {"dk": 17.92, "k": 4.96,  "s_hex": 5.0},
    "M10": {"dk": 22.40, "k": 6.20,  "s_hex": 6.0},
}

def make_countersunk(size, length, thread_type="cosmetic"):
    """
    Generate an ISO 10642 countersunk socket head cap screw.

    The head is a truncated cone (90-degree included angle)
    with a hex socket in the flat top.
    """
    td = THREAD_DATA[size]
    cd = COUNTERSUNK_DATA[size]
    d = td["d"]
    P = td["P"]
    dk = cd["dk"]        # head outer diameter
    k = cd["k"]          # head height (cone depth)
    s_hex = cd["s_hex"]  # socket size

    # ─── Head: truncated cone ───
    head = (
        cq.Workplane("XY")
        .circle(dk / 2.0)                # bottom of cone (flush surface)
        .workplane(offset=k)
        .circle(d / 2.0)                  # top of cone (meets shank)
        .loft()
    )

    # Cut hex socket
    hex_e = s_hex / math.cos(math.radians(30))
    socket_depth = k * 0.55
    socket_cut = (
        cq.Workplane("XY")
        .polygon(6, hex_e)
        .extrude(socket_depth)
    )
    head = head.cut(socket_cut)

    # ─── Body (thread) ───
    # For countersunk, almost the entire length is threaded
    if thread_type == "helical":
        thread = make_thread(d, P, length, external=True)
    else:
        thread = make_cosmetic_thread(d, P, length, external=True)
    thread = thread.translate((0, 0, k))  # starts at top of cone

    return head.union(thread)
```

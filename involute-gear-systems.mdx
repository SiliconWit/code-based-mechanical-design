## Involute Gear Mathematics

<InArticleAd />


Two smooth discs pressed together turn each other at a steady speed ratio, but under load they slip. Teeth stop the slip. The tooth shape must then keep that steady ratio, or the driven gear speeds up and slows down as each tooth passes, and the machine shakes.

The involute curve does this. The point where two involute teeth touch moves along one straight line, the line of action, so the ratio stays constant, even when the shafts are a little too far apart.

### Fundamental Gear Parameters

<CardGrid>
  <Card title="Module (m)" icon="setting">
    The size of the teeth: the pitch circle diameter $d$ divided by the number of teeth $z$, $m = d / z$, in mm. Standard modules (ISO 54) include 1, 1.25, 1.5, 2, 2.5 and 3 mm.
  </Card>
  <Card title="Pressure Angle (alpha)" icon="setting">
    The angle between the tooth face and a radial line at the pitch circle. A tooth pushes its partner along a line tilted by this angle, so part of the force pushes the shafts apart. Standard value: $\alpha = 20°$ (ISO 53).
  </Card>
  <Card title="Number of Teeth (z)" icon="setting">
    With too few teeth the cutting tool removes part of the tooth root. This is undercut, and it weakens the tooth. The limit $z_{min} = 2/\sin^2\alpha$ is 17.1 for $\alpha = 20°$, and 17 teeth is accepted in practice.
  </Card>
  <Card title="Face Width (b)" icon="setting">
    The thickness of the gear along the shaft, in mm, usually $8m$ to $12m$. A wider face carries more load only if the shafts are parallel enough for the whole width to touch.
  </Card>
</CardGrid>

### Circle Definitions

Four circles with the same center fix the shape of the teeth. The pitch circles of two gears are the two discs described above.

| Circle | Symbol | Formula | Description |
|--------|--------|---------|-------------|
| Pitch circle | $d$ | $d = m \cdot z$ | Where the two gears roll on each other |
| Base circle | $d_b$ | $d_b = d \cdot \cos(\alpha)$ | Where the involute curve starts |
| Addendum circle | $d_a$ | $d_a = d + 2m$ | Tips of the teeth |
| Dedendum circle | $d_f$ | $d_f = d - 2.5m$ | Bottom of the gaps between teeth |

A tooth rises one module above the pitch circle (the **addendum**, $h_a = m$) and the gap goes 1.25 modules below it (the **dedendum**, $h_f = 1.25m$). The extra $0.25m$ is clearance, so that a tip never touches the bottom of a gap.

For the example gear, $m = 2$ mm, $z = 20$, $\alpha = 20°$: $d = 40$ mm, $d_b = 37.59$ mm, $d_a = 44$ mm and $d_f = 35$ mm.

### The Involute Curve

Wind a string on a circle, then unwind it and keep it tight. The end of the string draws the involute of that circle. In a gear the circle is the base circle, with radius $r_b$ in mm. When the string has unwound by the angle $t$, in radians, its end is at:

$$x(t) = r_b \cdot (\cos(t) + t \cdot \sin(t))$$

$$y(t) = r_b \cdot (\sin(t) - t \cdot \cos(t))$$

That point is $r_b\sqrt{1 + t^2}$ from the center. As the curve moves outward it also turns away from the radius on which it started. Where it crosses the pitch circle, it has turned by the **involute function** of the pressure angle, in radians:

$$\text{inv}(\alpha) = \tan(\alpha) - \alpha$$

For $\alpha = 20°$ this is 0.0149 rad, a little less than one degree.

### Tooth Angular Thickness

On the pitch circle, teeth and gaps are equally wide. The angle from one tooth to the next is $2\pi/z$ radians, so a tooth covers $\pi/z$. The code builds each tooth from its center line, so it uses half of that, from the center line to one flank (a working side of the tooth):

$$\theta_{half} = \frac{\pi}{2z}$$

## Involute Profile Generation in Python

<InArticleAd />


These three functions turn the equations into points that CadQuery can join. The last one walks along the curve from the base circle to the tip circle and returns 21 points. As a check, its last point must lie at the tip radius, 22 mm for the example gear.

```python
import cadquery as cq
import math
import numpy as np

def involute_point(r_base, t):
    """
    Calculate a single point on the involute of a circle.

    Parameters:
        r_base (float): Base circle radius in mm
        t (float): Involute parameter (unwinding angle in radians)

    Returns:
        tuple: (x, y) coordinates of the involute point
    """
    x = r_base * (math.cos(t) + t * math.sin(t))
    y = r_base * (math.sin(t) - t * math.cos(t))
    return (x, y)

def involute_function(alpha):
    """
    The involute function: inv(alpha) = tan(alpha) - alpha.

    Parameters:
        alpha (float): Angle in radians

    Returns:
        float: Involute function value
    """
    return math.tan(alpha) - alpha

def generate_involute_profile(r_base, r_tip, num_points=20):
    """
    Generate a list of points along an involute curve from the
    base circle to the tip circle.

    Parameters:
        r_base (float): Base circle radius (mm)
        r_tip (float): Addendum (tip) circle radius (mm)
        num_points (int): Number of points to generate

    Returns:
        list: List of (x, y) tuples along the involute
    """
    # Calculate the parameter t at the tip circle
    # At any point on the involute, the distance from center is:
    #   r = r_base * sqrt(1 + t^2)
    # So: t_tip = sqrt((r_tip/r_base)^2 - 1)
    t_tip = math.sqrt((r_tip / r_base) ** 2 - 1)

    points = []
    for i in range(num_points + 1):
        t = t_tip * i / num_points
        pt = involute_point(r_base, t)
        points.append(pt)

    return points
```

### Building a Complete Tooth Profile

A tooth has two involute flanks that mirror each other. The involute above starts on the X-axis, so the code turns it clockwise by $\pi/(2z) + \text{inv}(\alpha)$. The flank then crosses the pitch circle half a tooth thickness below the X-axis, and its mirror image half a thickness above.

The involute exists only outside the base circle. In a 20° gear with fewer than 42 teeth the gap goes deeper than that, and the generator joins the two with a straight radial line. A real cutting tool leaves a rounded fillet there, so the drawn root is approximate.

```python
def generate_tooth_profile(module, num_teeth, pressure_angle_deg=20.0,
                           num_points=20):
    """
    Generate the 2D profile of a single gear tooth centered at
    the positive X-axis.

    Returns left flank, tip arc, and right flank as point lists.
    """
    alpha = math.radians(pressure_angle_deg)

    # Circle radii
    r_pitch = module * num_teeth / 2.0
    r_base = r_pitch * math.cos(alpha)
    r_tip = r_pitch + module               # addendum circle
    r_root = r_pitch - 1.25 * module       # dedendum circle

    # Handle case where base circle is larger than root circle
    r_start = max(r_base, r_root)

    # Generate one flank involute, from the base circle to the tip
    right_flank = generate_involute_profile(r_base, r_tip, num_points)

    # Tooth angular half-thickness at the pitch circle = pi/(2*z)
    # (the full tooth thickness angle is pi/z, half of the angular pitch 2*pi/z)
    inv_alpha = involute_function(alpha)

    # Angular half-thickness at the base circle
    # The involute starts at angle 0 on the base circle.
    # At pitch circle: angle = inv(alpha)
    # Tooth half-thickness at pitch circle = pi/(2*z)
    # So the tooth center offset = pi/(2*z) + inv(alpha)
    tooth_half_angle = math.pi / (2 * num_teeth) + inv_alpha

    # Rotate the flank so the tooth is centered on the X-axis.
    # The involute curls toward larger angles as it moves outward, so
    # it must start at -tooth_half_angle: the flank then comes closer
    # to the center line toward the tip, and the tooth gets narrower.
    right_rotated = []
    for (x, y) in right_flank:
        angle = -tooth_half_angle
        xr = x * math.cos(angle) - y * math.sin(angle)
        yr = x * math.sin(angle) + y * math.cos(angle)
        right_rotated.append((xr, yr))

    # Mirror to get the other flank
    left_rotated = [(x, -y) for (x, y) in right_rotated]
    left_rotated.reverse()  # reverse order (tip to base) for a continuous path

    return left_rotated, right_rotated, r_root, r_tip
```

## Single Gear Function: `make_spur_gear()`

<InArticleAd />


This function makes one flank, mirrors it, and copies the tooth $z$ times around the center, with points on the root circle between teeth. The closed outline is extruded to the face width and given a bore (the hole for the shaft). The third tab prints the dimensions with no geometry: for `gear_dimensions(2.0, 20)` look for a base diameter of 37.588 mm.

```python
def make_spur_gear(module, num_teeth, width, pressure_angle_deg=20.0,
                   bore_diameter=0, hub_diameter=0, hub_length=0,
                   num_points=20):
    """
    Generate a complete involute spur gear.

    Parameters:
        module (float): Gear module in mm (e.g., 2.0)
        num_teeth (int): Number of teeth (e.g., 20)
        width (float): Face width (gear thickness) in mm
        pressure_angle_deg (float): Pressure angle in degrees (default 20)
        bore_diameter (float): Central bore diameter in mm (0 = no bore)
        hub_diameter (float): Hub outer diameter in mm (0 = no hub)
        hub_length (float): Hub length extending from face in mm
        num_points (int): Involute curve resolution

    Returns:
        cq.Workplane: Complete spur gear solid
    """
    alpha = math.radians(pressure_angle_deg)

    # ─── Calculate circle radii ───
    r_pitch = module * num_teeth / 2.0
    r_base = r_pitch * math.cos(alpha)
    r_tip = r_pitch + module
    r_root = r_pitch - 1.25 * module

    # Ensure root radius is positive and reasonable
    if r_root < 0:
        raise ValueError(
            f"Root circle is negative (r_root={r_root:.2f}). "
            f"Increase module or num_teeth."
        )

    r_start = max(r_base, r_root)

    # ─── Involute function value at pressure angle ───
    inv_alpha = involute_function(alpha)

    # Tooth half-angle at the base circle
    tooth_half_angle = math.pi / (2 * num_teeth) + inv_alpha

    # ─── Generate one tooth profile ───
    # Right flank: involute from r_start (base or root circle,
    # whichever is larger) to the tip
    t_start = math.sqrt((r_start / r_base) ** 2 - 1)
    t_tip = math.sqrt((r_tip / r_base) ** 2 - 1)
    right_pts = []
    for i in range(num_points + 1):
        t = t_start + (t_tip - t_start) * i / num_points
        pt = involute_point(r_base, t)
        # Rotate by -tooth_half_angle to center tooth on X-axis.
        # The involute curls toward larger angles as it moves outward,
        # so this flank starts below the X-axis and comes closer to it
        # toward the tip: the tooth gets narrower, as it must.
        x = pt[0] * math.cos(-tooth_half_angle) \
          - pt[1] * math.sin(-tooth_half_angle)
        y = pt[0] * math.sin(-tooth_half_angle) \
          + pt[1] * math.cos(-tooth_half_angle)
        right_pts.append((x, y))

    # Left flank: mirror of right flank, in reverse order (tip to root)
    left_pts = [(x, -y) for (x, y) in right_pts]
    left_pts.reverse()

    # Angle of the flank start point, measured from the tooth center line
    flank_start_angle = tooth_half_angle - (t_start - math.atan(t_start))

    # ─── Build the complete gear outline ───
    # Strategy: for each tooth, draw right_flank (root to tip) -> tip_arc
    #           -> left_flank (tip to root), then root_arc to the next tooth
    angular_pitch = 2 * math.pi / num_teeth

    all_points = []
    for i in range(num_teeth):
        angle = i * angular_pitch

        cos_a = math.cos(angle)
        sin_a = math.sin(angle)

        # Rotate right flank points (root to tip)
        for (x, y) in right_pts:
            xr = x * cos_a - y * sin_a
            yr = x * sin_a + y * cos_a
            all_points.append((xr, yr))

        # Tip arc point (at the tip of the tooth)
        # between the last point of the right flank and the first
        # point of the left flank
        tip_mid_x = r_tip * math.cos(angle)
        tip_mid_y = r_tip * math.sin(angle)
        all_points.append((tip_mid_x, tip_mid_y))

        # Rotate left flank points (tip to root)
        for (x, y) in left_pts:
            xr = x * cos_a - y * sin_a
            yr = x * sin_a + y * cos_a
            all_points.append((xr, yr))

        # Root arc: connect to next tooth's right flank.
        # Points on the root circle: the midpoint of the gap, and (see
        # below) the points under the end of this tooth and the start
        # of the next one
        root_a = angle + flank_start_angle
        root_b = angle + angular_pitch - flank_start_angle
        root_angles = [(root_a + root_b) / 2.0]
        if r_start > r_root:
            # Flanks start on the base circle: add the two points
            # that join them to the root circle with radial lines
            root_angles = [root_a] + root_angles + [root_b]
        for root_angle in root_angles:
            root_x = r_root * math.cos(root_angle)
            root_y = r_root * math.sin(root_angle)
            all_points.append((root_x, root_y))

    # ─── Create the 2D profile as a CadQuery wire ───
    # polyline().close() joins the last point back to the first one
    wp = cq.Workplane("XY")
    gear_profile = wp.polyline(all_points).close()

    # Extrude to create the 3D gear body
    gear = gear_profile.extrude(width)

    # ─── Add bore if specified ───
    if bore_diameter > 0:
        gear = (
            gear
            .faces(">Z")
            .workplane()
            .hole(bore_diameter)
        )

    # ─── Add hub if specified ───
    if hub_diameter > 0 and hub_length > 0:
        hub = (
            cq.Workplane("XY")
            .workplane(offset=width)
            .circle(hub_diameter / 2.0)
            .extrude(hub_length)
        )
        gear = gear.union(hub)

        # Bore through the hub as well
        if bore_diameter > 0:
            hub_bore = (
                cq.Workplane("XY")
                .workplane(offset=width)
                .circle(bore_diameter / 2.0)
                .extrude(hub_length)
            )
            gear = gear.cut(hub_bore)

    # ─── Add keyway (optional, for shaft coupling) ───
    # Standard DIN 6885 keyway dimensions could be added here

    return gear
```

```python
    Print all key dimensions for a spur gear.

    Parameters:

        num_teeth (int): Number of teeth
        pressure_angle_deg (float): Pressure angle in degrees
```

## Meshing Gear Pair

<InArticleAd />


Two involute gears mesh only when they have the same module and the same pressure angle. The tooth counts are free, and they set the ratio. The smaller gear of a pair is called the pinion.

### Center Distance Calculation

The two pitch circles must touch, so the shafts are apart by the sum of the two pitch radii. For tooth counts $z_1$ (pinion) and $z_2$ (gear) and module $m$ in mm:

$$a = \frac{m \cdot (z_1 + z_2)}{2}$$

This is the **standard center distance** $a$, in mm: 60 mm for 20 and 40 teeth at module 2. At exactly this distance the teeth touch on both sides, and real teeth with small errors would jam. So the shafts are set further apart by a small distance $\Delta a$, in mm.

### Contact Ratio

The next pair of teeth must touch before the last pair separates. The **contact ratio** $\varepsilon$ is the average number of tooth pairs in contact: at 1.6, two pairs share the load for 60 percent of the time. For smooth running, $\varepsilon > 1.2$ is required. It is the length of the line of action on which teeth touch, divided by the tooth spacing along that line:

$$\varepsilon = \frac{\sqrt{r_{a1}^2 - r_{b1}^2} + \sqrt{r_{a2}^2 - r_{b2}^2} - a \cdot \sin(\alpha)}{\pi \cdot m \cdot \cos(\alpha)}$$

Here $r_{a1}$, $r_{a2}$ are the tip radii and $r_{b1}$, $r_{b2}$ the base circle radii, in mm. The calculator in the third tab below gives 1.635 for 20 and 40 teeth. It gives 1.593 for a pinion of 14 teeth, but the formula does not know that this pinion is undercut, so the real value is lower.

### Backlash

**Backlash** is the play between meshing teeth: hold one gear still, and it is the distance the other can rock, measured along the pitch circle. Printed teeth are never exact and parts expand when warm, so some play is needed: 0.15 to 0.25 mm for FDM (filament) prints, 0.08 to 0.15 mm for resin prints, 0.10 to 0.20 mm for sintered nylon, and 0.02 to 0.05 mm for machined gears.

The code below makes backlash with a larger center distance, and its argument named `backlash` is really $\Delta a$. Moving the shafts apart by $\Delta a$ opens a play of $2\,\Delta a \tan\alpha$, so `backlash=0.15` gives about 0.11 mm of play at 20°. The function also turns the larger gear by half a tooth, so that a gap faces the pinion.

```python
def make_gear_pair(module, z1, z2, width, pressure_angle_deg=20.0,
                   backlash=0.1, bore1=0, bore2=0):
    """
    Generate a meshing pair of involute spur gears.

    Parameters:
        module (float): Common module in mm
        z1 (int): Number of teeth on pinion (smaller gear)
        z2 (int): Number of teeth on gear (larger gear)
        width (float): Face width in mm (same for both)
        pressure_angle_deg (float): Common pressure angle
        backlash (float): Backlash allowance in mm
        bore1 (float): Pinion bore diameter (0 = no bore)
        bore2 (float): Gear bore diameter (0 = no bore)

    Returns:
        tuple: (pinion, gear, center_distance), both positioned for meshing
    """
    alpha = math.radians(pressure_angle_deg)

    # ─── Standard center distance ───
    r1 = module * z1 / 2.0   # pinion pitch radius
    r2 = module * z2 / 2.0   # gear pitch radius
    center_distance = r1 + r2 + backlash

    # ─── Contact ratio check ───
    r_a1 = r1 + module           # pinion addendum radius
    r_b1 = r1 * math.cos(alpha)  # pinion base radius
    r_a2 = r2 + module           # gear addendum radius
    r_b2 = r2 * math.cos(alpha)  # gear base radius

    eps_num = (
        math.sqrt(r_a1**2 - r_b1**2) +
        math.sqrt(r_a2**2 - r_b2**2) -
        center_distance * math.sin(alpha)
    )
    eps_den = math.pi * module * math.cos(alpha)
    contact_ratio = eps_num / eps_den

    print(f"Gear pair: z1={z1}, z2={z2}, m={module}")
    print(f"  Center distance: {center_distance:.3f} mm")
    print(f"  Gear ratio: {z2/z1:.3f}:1")
    print(f"  Contact ratio: {contact_ratio:.3f}")
    if contact_ratio < 1.2:
        print(f"  WARNING: Contact ratio < 1.2: consider more teeth")

    # ─── Generate both gears ───
    pinion = make_spur_gear(
        module, z1, width,
        pressure_angle_deg=pressure_angle_deg,
        bore_diameter=bore1,
    )
    gear = make_spur_gear(
        module, z2, width,
        pressure_angle_deg=pressure_angle_deg,
        bore_diameter=bore2,
    )

    # ─── Position the gears for meshing ───
    # Pinion at origin, gear offset by center distance along X
    # Rotate the gear so teeth interleave properly
    # The angular offset for meshing:
    #   half-tooth rotation on the gear to fit between pinion teeth
    # (the extra half turn makes this correct for odd tooth counts too:
    #  the gear must show a tooth gap, not a tooth, toward the pinion)
    mesh_angle = math.pi + math.pi / z2  # half turn + half a tooth pitch

    gear = (
        gear
        .rotate((0, 0, 0), (0, 0, 1), math.degrees(mesh_angle))
        .translate((center_distance, 0, 0))
    )

    return pinion, gear, center_distance
```

```python
def contact_ratio_analysis(module, z1, z2, pressure_angle_deg=20.0):
    """
    Detailed contact ratio analysis for a gear pair.
    """
    alpha = math.radians(pressure_angle_deg)

    r1 = module * z1 / 2.0
    r2 = module * z2 / 2.0
    a = r1 + r2   # standard center distance

    r_a1 = r1 + module
    r_b1 = r1 * math.cos(alpha)
    r_a2 = r2 + module
    r_b2 = r2 * math.cos(alpha)

    # Length of path of contact
    path_approach = math.sqrt(r_a2**2 - r_b2**2) - r2 * math.sin(alpha)
    path_recess = math.sqrt(r_a1**2 - r_b1**2) - r1 * math.sin(alpha)
    total_path = path_approach + path_recess

    # Base pitch
    p_b = math.pi * module * math.cos(alpha)

    # Contact ratio
    eps = total_path / p_b

    print(f"{'='*50}")
    print(f"Contact Ratio Analysis: z1={z1}, z2={z2}, m={module}")
    print(f"{'='*50}")
    print(f"Path of approach:  {path_approach:.3f} mm")
    print(f"Path of recess:    {path_recess:.3f} mm")
    print(f"Total path:        {total_path:.3f} mm")
    print(f"Base pitch:        {p_b:.3f} mm")
    print(f"Contact ratio:     {eps:.3f}")
    print(f"Status: {'OK' if eps >= 1.2 else 'LOW: increase teeth'}")
    print(f"{'='*50}")

    return eps
```

## Lewis Bending Stress Verification

<InArticleAd />


A gear with the right shape can still fail: a tooth can break off at its root. A tooth is like a short shelf fixed to a wall. A load on its free end stresses it most where it meets the wall, and for a tooth that place is the root. The **Lewis equation** is the classical estimate of this stress. It treats the tooth as such a beam (a cantilever) with the whole load on its tip.

### The Lewis Equation

$$\sigma_b = \frac{F_t}{b \cdot m \cdot Y}$$

where:
- $\sigma_b$ = bending stress at the tooth root (MPa, the same as N/mm²)
- $F_t$ = tangential force on the tooth (N)
- $b$ = face width (mm)
- $m$ = module (mm)
- $Y$ = Lewis form factor (a number with no unit, set by the tooth count and the pressure angle)

The force comes from the torque $T$ on the gear, in N·mm, and acts at the pitch radius $d/2$:

$$F_t = \frac{2T}{d} = \frac{2T}{m \cdot z}$$

Take the first example in the code: $m = 2$ mm, $z = 25$, $b = 12$ mm and a torque of 2 N·m, which is 2,000 N·mm. Then $d = 50$ mm, $F_t = 2 \times 2000 / 50 = 80$ N, and with $Y = 0.340$ the stress is $80 / (12 \times 2 \times 0.340) = 9.8$ MPa. The code allows printed PLA 25 MPa, so the safety factor is $25 / 9.8 = 2.6$.

:::caution[What the Lewis equation leaves out]
The equation ignores the stress concentration in the root fillet, the extra load from speed and shock, surface wear, and heat, which softens plastic gears. Gear standards (ISO 6336, AGMA 2001) add a factor for each. Keep a safety factor of at least 1.5, and test a printed gear under its real load.
:::

### Lewis Form Factor

A gear with more teeth has teeth that are wider at the root, so $Y$ rises with the tooth count: 0.245 for 12 teeth, 0.320 for 20, 0.421 for 60 and 0.484 for a straight rack, for $\alpha = 20°$. The code holds the full table and interpolates between its rows.

### Stress Calculation Function

The function looks up $Y$, computes the stress as above, and compares it with an allowable value for six materials.

```python
def lewis_bending_stress(module, num_teeth, width, torque_Nm,
                         pressure_angle_deg=20.0):
    """
    Calculate the Lewis bending stress at the tooth root.

    Parameters:
        module (float): Gear module in mm
        num_teeth (int): Number of teeth
        width (float): Face width in mm
        torque_Nm (float): Applied torque in N-m
        pressure_angle_deg (float): Pressure angle in degrees

    Returns:
        dict: Stress analysis results
    """
    # Lewis form factor lookup (20-degree pressure angle)
    lewis_table = {
        12: 0.245, 14: 0.276, 17: 0.303, 20: 0.320,
        25: 0.340, 30: 0.358, 35: 0.374, 40: 0.389,
        45: 0.399, 50: 0.408, 60: 0.421, 75: 0.435,
        100: 0.447, 150: 0.460, 200: 0.468, 300: 0.472,
    }

    # Interpolate Lewis form factor
    keys = sorted(lewis_table.keys())
    if num_teeth <= keys[0]:
        Y = lewis_table[keys[0]]
    elif num_teeth >= keys[-1]:
        Y = lewis_table[keys[-1]]
    else:
        # Linear interpolation
        for i in range(len(keys) - 1):
            if keys[i] <= num_teeth <= keys[i+1]:
                t = (num_teeth - keys[i]) / (keys[i+1] - keys[i])
                Y = lewis_table[keys[i]] * (1 - t) \
                  + lewis_table[keys[i+1]] * t
                break

    # Pitch circle diameter
    d = module * num_teeth  # mm

    # Tangential force
    torque_Nmm = torque_Nm * 1000.0  # convert to N-mm
    F_t = 2 * torque_Nmm / d         # tangential force in N

    # Lewis bending stress
    sigma_b = F_t / (width * module * Y)  # MPa

    # Common material allowable stresses
    materials = {
        "PLA (3D printed)":        25,   # MPa
        "ABS (3D printed)":        30,
        "Nylon PA12 (SLS)":        45,
        "Acetal (POM)":            60,
        "Steel (case hardened)":   250,
        "Steel (through hardened)": 350,
    }

    results = {
        "module": module,
        "num_teeth": num_teeth,
        "width": width,
        "torque_Nm": torque_Nm,
        "pitch_diameter": d,
        "lewis_factor_Y": Y,
        "tangential_force_N": F_t,
        "bending_stress_MPa": sigma_b,
    }

    print(f"{'='*55}")
    print(f"Lewis Bending Stress Analysis")
    print(f"{'='*55}")
    print(f"Module:              {module} mm")
    print(f"Teeth:               {num_teeth}")
    print(f"Face width:          {width} mm")
    print(f"Torque:              {torque_Nm} N-m")
    print(f"Pitch diameter:      {d:.1f} mm")
    print(f"Lewis factor Y:      {Y:.3f}")
    print(f"Tangential force:    {F_t:.1f} N")
    print(f"Bending stress:      {sigma_b:.1f} MPa")
    print(f"{'─'*55}")
    print(f"Material Comparison:")
    for mat, allowable in materials.items():
        safety = allowable / sigma_b if sigma_b > 0 else float('inf')
        status = "OK" if safety >= 1.5 else "FAIL"
        print(f"  {mat:30s}  "
              f"allow={allowable:>4d} MPa  "
              f"SF={safety:.2f}  [{status}]")
    print(f"{'='*55}")

    return results
```

```python
    Uses the Lewis equation solved for width:
        b = F_t / (sigma_allow / SF * m * Y)
    """
    # Get Lewis factor (simplified lookup)
    lewis_table = {
        12: 0.245, 14: 0.276, 17: 0.303, 20: 0.320,

        60: 0.421, 75: 0.435, 100: 0.447,

                break
```

## Multi-Stage Gear Train with Housing

<InArticleAd />


A small motor turns fast with little torque, and most loads need the opposite. When a pinion drives a gear with three times as many teeth, the speed falls to one third and the torque rises three times. A ratio of 9:1 in one pair would need a very large gear, so the final project uses two pairs in a row, and their ratios multiply.

### Gear Train Design Parameters

Each stage has a ratio of 3:1, module 2.0 mm and a face width of 10 mm. The middle shaft carries two gears that turn together: the 54-tooth gear of stage 1 and the 20-tooth pinion of stage 2.

```text
 motor            middle             output
 shaft            shaft              shaft
+------+  mesh  +------+
| 18 T |------->| 54 T |
+------+        +------+
                | 20 T |    mesh   +------+
                +------+---------->| 60 T |
                                   +------+
 1000 RPM        333 RPM            111 RPM
 0.5 N·m         1.5 N·m            4.5 N·m
```

The torques ignore friction, so the real output is a little lower. The first block computes the ratios and the center distances, 72 mm and 80 mm, which place the three shafts on one line.


### Gear Train Assembly Function

`make_gear_train` builds the four gears, places stage 2 in a second layer 3 mm above stage 1, and adds three shafts of 8 mm. `make_gear_housing` (second tab) makes a box with 2 mm of clearance to the gear tips, holes for the bearings (the rings that let a shaft turn in the wall) and four mounting feet.

```python
def make_gear_train():
    """
    Generate a complete two-stage gear train assembly:
    4 gears, 3 shafts, and a housing with bearing bores.

    Returns:
        dict: Dictionary of named components
    """
    # ─── Design parameters ───
    m = 2.0           # module
    z1, z2 = 18, 54   # stage 1 teeth
    z3, z4 = 20, 60   # stage 2 teeth
    fw = 10.0          # face width
    backlash = 0.15    # for 3D printing

    shaft_dia = 8.0
    bore_dia = 8.2     # slight clearance for shaft
    bearing_od = 16.0
    bearing_width = 5.0
    wall = 4.0         # housing wall thickness

    # ─── Center distances ───
    cd1 = m * (z1 + z2) / 2.0 + backlash
    cd2 = m * (z3 + z4) / 2.0 + backlash

    # Shaft X positions
    x_in = 0.0
    x_mid = cd1
    x_out = cd1 + cd2

    # ─── Generate the four gears ───
    gear1 = make_spur_gear(m, z1, fw, bore_diameter=bore_dia)
    gear2 = make_spur_gear(m, z2, fw, bore_diameter=bore_dia)
    gear3 = make_spur_gear(m, z3, fw, bore_diameter=bore_dia)
    gear4 = make_spur_gear(m, z4, fw, bore_diameter=bore_dia)

    # Position gears:
    # Stage 1: gear1 at input shaft, gear2 at intermediate shaft
    # Stage 2: gear3 at intermediate shaft (offset in Z), gear4 at output
    gear1_z = bearing_width + wall  # first gear layer Z position
    gear3_z = gear1_z + fw + 3.0   # second stage Z offset (3mm gap)

    # Rotate gear2 for meshing with gear1
    mesh_angle_1 = 180.0 / z2
    gear2 = gear2.rotate((0, 0, 0), (0, 0, 1), mesh_angle_1)

    # Rotate gear4 for meshing with gear3
    mesh_angle_2 = 180.0 / z4
    gear4 = gear4.rotate((0, 0, 0), (0, 0, 1), mesh_angle_2)

    # Translate to positions
    gear1 = gear1.translate((x_in, 0, gear1_z))
    gear2 = gear2.translate((x_mid, 0, gear1_z))
    gear3 = gear3.translate((x_mid, 0, gear3_z))
    gear4 = gear4.translate((x_out, 0, gear3_z))

    # ─── Shafts ───
    total_length = gear3_z + fw + wall + bearing_width
    shaft_in = (
        cq.Workplane("XY")
        .circle(shaft_dia / 2.0)
        .extrude(total_length)
        .translate((x_in, 0, 0))
    )
    shaft_mid = (
        cq.Workplane("XY")
        .circle(shaft_dia / 2.0)
        .extrude(total_length)
        .translate((x_mid, 0, 0))
    )
    shaft_out = (
        cq.Workplane("XY")
        .circle(shaft_dia / 2.0)
        .extrude(total_length)
        .translate((x_out, 0, 0))
    )

    # ─── Housing ───
    housing = make_gear_housing(
        x_in, x_mid, x_out,
        m, z1, z2, z3, z4,
        fw, wall, bearing_od, bearing_width,
        gear1_z, gear3_z,
    )

    return {
        "gear1_input_pinion": gear1,
        "gear2_stage1_gear": gear2,
        "gear3_stage2_pinion": gear3,
        "gear4_output_gear": gear4,
        "shaft_input": shaft_in,
        "shaft_intermediate": shaft_mid,
        "shaft_output": shaft_out,
        "housing": housing,
    }
```

```python
def make_gear_housing(x_in, x_mid, x_out,
                      module, z1, z2, z3, z4,
                      face_width, wall, bearing_od, bearing_width,
                      z_stage1, z_stage2):
    """
    Generate a gear train housing with bearing bores and
    inspection/assembly openings.

    The housing is a box-like structure with:
    - Bearing bores at each shaft location (both sides)
    - Clearance for all gears
    - Mounting feet
    """
    # ─── Calculate gear envelopes ───
    r_tip1 = module * z1 / 2.0 + module   # input pinion tip radius
    r_tip2 = module * z2 / 2.0 + module   # stage 1 gear tip radius
    r_tip3 = module * z3 / 2.0 + module   # stage 2 pinion tip radius
    r_tip4 = module * z4 / 2.0 + module   # output gear tip radius

    clearance = 2.0  # mm clearance between gear tips and housing

    # Housing envelope
    max_r = max(r_tip1, r_tip2, r_tip3, r_tip4) + clearance
    y_min = -max_r - wall
    y_max = max_r + wall
    x_min = x_in - r_tip1 - clearance - wall
    x_max = x_out + r_tip4 + clearance + wall
    z_min = 0
    z_max = z_stage2 + face_width + wall + bearing_width

    housing_width = x_max - x_min
    housing_height = y_max - y_min
    housing_depth = z_max - z_min

    # Center offset
    x_center = (x_min + x_max) / 2.0
    y_center = 0.0

    # ─── Outer shell ───
    housing = (
        cq.Workplane("XY")
        .box(housing_width, housing_height, housing_depth,
             centered=(True, True, False))
        .translate((x_center, y_center, z_min))
    )

    # ─── Hollow out the interior ───
    interior = (
        cq.Workplane("XY")
        .box(housing_width - 2 * wall,
             housing_height - 2 * wall,
             housing_depth - 2 * wall,
             centered=(True, True, False))
        .translate((x_center, y_center, wall))
    )
    housing = housing.cut(interior)

    # ─── Bearing bores (cylindrical holes for bearings) ───
    # Each shaft gets bearing bores on both the front and back walls
    shaft_positions = [
        (x_in, 0),
        (x_mid, 0),
        (x_out, 0),
    ]

    for (sx, sy) in shaft_positions:
        # Front wall bearing bore
        front_bore = (
            cq.Workplane("XY")
            .workplane(offset=0)
            .center(sx, sy)
            .circle(bearing_od / 2.0)
            .extrude(bearing_width + wall)
        )
        housing = housing.cut(front_bore)

        # Back wall bearing bore
        back_bore = (
            cq.Workplane("XY")
            .workplane(offset=z_max - bearing_width - wall)
            .center(sx, sy)
            .circle(bearing_od / 2.0)
            .extrude(bearing_width + wall)
        )
        housing = housing.cut(back_bore)

        # Through-hole for shaft (smaller than bearing bore)
        shaft_hole = (
            cq.Workplane("XY")
            .center(sx, sy)
            .circle(bearing_od / 2.0 - 1.0)  # shaft clearance
            .extrude(z_max)
        )
        housing = housing.cut(shaft_hole)

    # ─── Mounting feet ───
    foot_width = 15.0
    foot_depth = 5.0
    foot_length = 20.0

    for x_pos in [x_min + wall, x_max - wall]:
        for y_pos in [y_min + wall, y_max - wall]:
            foot = (
                cq.Workplane("XY")
                .box(foot_length, foot_width, foot_depth,
                     centered=(True, True, False))
                .translate((x_pos, y_pos, -foot_depth))
            )
            # Mounting hole in each foot
            foot_hole = (
                cq.Workplane("XY")
                .workplane(offset=-foot_depth)
                .center(x_pos, y_pos)
                .circle(2.5)  # M5 clearance hole
                .extrude(foot_depth)
            )
            housing = housing.union(foot).cut(foot_hole)

    return housing
```

## Complete Stress Verification for the Gear Train

<InArticleAd />


Each gear carries a different torque, so the function below runs the Lewis check four times. With 0.5 N·m at the input it reports 4.5 and 3.4 MPa for stage 1, and 11.7 and 8.9 MPa for stage 2. The highest stress is in the 20-tooth pinion of stage 2: it carries three times the input torque on a small diameter. In a reduction train, check the last pinion first.

```python
def verify_gear_train(input_torque_Nm, input_rpm):
    """
    Run Lewis bending stress analysis on all four gears
    in the two-stage gear train.
    """
    m = 2.0
    z1, z2 = 18, 54
    z3, z4 = 20, 60
    fw = 10.0

    ratio_1 = z2 / z1
    ratio_2 = z4 / z3

    # Stage 1: input pinion carries input torque
    T1 = input_torque_Nm
    rpm1 = input_rpm

    # Stage 1 gear (and stage 2 pinion) carries amplified torque
    T2 = T1 * ratio_1
    rpm2 = rpm1 / ratio_1

    # Stage 2 gear carries final torque
    T3 = T2 * ratio_2
    rpm3 = rpm2 / ratio_2

    print(f"\n{'='*60}")
    print(f"GEAR TRAIN STRESS VERIFICATION")
    print(f"Input: {input_torque_Nm} N-m at {input_rpm} RPM")
    print(f"Output: {T3:.2f} N-m at {rpm3:.1f} RPM")
    print(f"{'='*60}\n")

    print("─── Stage 1 Pinion (z=18) ───")
    lewis_bending_stress(m, z1, fw, T1)

    print("\n─── Stage 1 Gear (z=54) ───")
    lewis_bending_stress(m, z2, fw, T2)

    print("\n─── Stage 2 Pinion (z=20) ───")
    lewis_bending_stress(m, z3, fw, T2)

    print("\n─── Stage 2 Gear (z=60) ───")
    lewis_bending_stress(m, z4, fw, T3)

# Verify: 0.5 N-m input at 1000 RPM (small DC motor)
verify_gear_train(0.5, 1000)
```

:::tip[Instrument it]
A gear train announces trouble through vibration: as teeth wear, pit, or chip, energy appears at the gear-mesh frequency (tooth count times shaft speed) and its harmonics. A MEMS accelerometer (ADXL345, or the wider-band ADXL1002) on the housing near the bearing picks this up, and a tachometer or encoder on the shaft lets you line the spectrum up with the mesh frequency. An ESP32 or STM32 reads them and can [flag the rising mesh tone](https://siliconwit.io) long before a tooth lets go, which matters even more for 3D-printed gears that wear faster than cut steel.
:::

## Design Guidelines for 3D-Printed Gears

<InArticleAd />


<CardGrid>
  <Card title="Minimum Teeth" icon="warning">
    Use at least 17 teeth to avoid undercut, and 20 or more so the tooth tips are thick enough to print cleanly.
  </Card>
  <Card title="Module Selection" icon="setting">
    For FDM printing with a 0.4 mm nozzle, use module 1.5 or larger. The tooth tip must be at least two nozzle widths (0.8 mm) wide.
  </Card>
  <Card title="Print Orientation" icon="rocket">
    Print gears flat on the build plate. The layers then run across each tooth, which gives the strongest tooth root.
  </Card>
  <Card title="Post-Processing" icon="approve-check">
    Lightly sand the tooth flanks with 400-grit paper and apply a thin coat of lithium grease. This reduces wear and noise.
  </Card>
</CardGrid>

## Advanced Topics: Profile Shift

<InArticleAd />


A pinion with fewer than 17 teeth is undercut. **Profile shift** is the usual cure: the gear is cut with the tool pulled outward by $x \cdot m$, where $x$ is the profile shift coefficient, a number with no unit. The tooth is then thicker at the root. The price is larger tip and root circles and a larger center distance:

$$d_a = m \cdot (z + 2 + 2x)$$

$$d_f = m \cdot (z - 2.5 + 2x)$$

$$a_{shifted} \approx \frac{m \cdot (z_1 + z_2)}{2} + m \cdot (x_1 + x_2)$$

The last formula is a first estimate: the exact center distance is slightly smaller. For a pinion with 14 teeth, $x = +0.3$ is typical. The function below only prints the shifted diameters. The solid it returns is still the standard gear, and building the shifted tooth is left as an exercise.

```python
def make_shifted_gear(module, num_teeth, width, shift_x,
                      pressure_angle_deg=20.0, bore_diameter=0):
    """
    Generate a spur gear with profile shift correction.

    Parameters:
        shift_x (float): Profile shift coefficient
                         (positive = outward, typical 0 to +0.5)
    """
    alpha = math.radians(pressure_angle_deg)

    # Modified circle radii
    r_pitch = module * num_teeth / 2.0
    r_base = r_pitch * math.cos(alpha)
    r_tip = (module * (num_teeth + 2 + 2 * shift_x)) / 2.0
    r_root = (module * (num_teeth - 2.5 + 2 * shift_x)) / 2.0

    print(f"Profile-shifted gear: z={num_teeth}, x={shift_x}")
    print(f"  Tip diameter:  {2*r_tip:.2f} mm "
          f"(standard: {module*(num_teeth+2):.2f} mm)")
    print(f"  Root diameter: {2*r_root:.2f} mm "
          f"(standard: {module*(num_teeth-2.5):.2f} mm)")

    # Use the same involute generation as make_spur_gear
    # but with modified tip and root radii
    gear = make_spur_gear(
        module, num_teeth, width,
        pressure_angle_deg=pressure_angle_deg,
        bore_diameter=bore_diameter,
    )
    # Note: for a full implementation, the involute generation
    # inside make_spur_gear would need to use r_tip and r_root
    # from the shifted values. This is left as an exercise.

    return gear
```

A solid printed part is heavy, slow to print and uses material in places that carry almost no load. A lattice, a regular network of thin members and open space, removes that material. But it has thousands of small features, too many to draw by hand, and it is easy to design one that is too weak or cannot be printed. In this lesson you generate strut lattices in CadQuery and smooth repeating surfaces called TPMS (triply periodic minimal surfaces) in NumPy, and you learn what a lattice costs in stiffness. #LatticeDesign #TPMS #AdditiveManufacturing

## Why Lattice Structures?

<InArticleAd />


A lattice does inside a part what a truss does in a bridge: it keeps the material that carries load and leaves the rest open. A lattice-filled part can weigh 50 to 90 percent less than the solid one.

The price is stiffness and strength, and it is higher than most people expect. In most lattices the thin members bend under load, and stiffness then falls with about the square of the density: a lattice with 20 percent of the material keeps about 4 percent of the stiffness, not 20 percent. Lattices whose members are pulled and pushed along their length lose stiffness only in proportion to the material removed. These are rough rules for low densities, so test a printed sample.

## Strut-Based Lattice Fundamentals

<InArticleAd />


A strut lattice is built from a **unit cell**: one small cube that holds a few straight rods (struts) joined at points (nodes). The cell is repeated in three directions, as a tile is repeated on a floor.

### Unit Cell Geometry

Three common unit cells differ in where the struts run:

| Unit Cell | Nodes | Struts | Where the struts run | Struts mostly |
|-----------|-------|--------|-------------|----------------------|
| Simple Cubic (SC) | 8 | 12 | Along the cube edges | Bend, except along the axes |
| Body-Centered Cubic (BCC) | 9 | 8 | From each corner to the center | Bend |
| Octet-Truss | 14 | 36 | Corners to face centers, and between face centers | Stretch |

The **relative density** $\bar{\rho}$ is the volume of the struts divided by the volume of the cell, a number from 0 to 1. A BCC cell of side $L$ (mm) has 8 struts of diameter $d$ (mm), each as long as half the cube diagonal, $\sqrt{3}L/2$. Eight cylinder volumes divided by the cell volume $L^3$ give:

$$
\bar{\rho}_{\text{BCC}} \approx 8 \cdot \frac{\pi d^2}{4} \cdot \frac{\sqrt{3} L / 2}{L^3} = \frac{\sqrt{3}\pi d^2}{L^2}
$$

For $d = 0.8$ mm and $L = 10$ mm this is $5.44 \times 0.64 / 100 = 0.035$, or 3.5 percent. The formula counts the material where struts cross more than once, so it reads too high for thick struts.

## CadQuery Strut-Based Lattice Implementation

<InArticleAd />


Each function below lists the nodes, makes a cylinder for every strut, joins them into one solid, and adds a small sphere at each node. The octet-truss tab uses `make_strut` from the BCC tab.

<Tabs>

```python
import cadquery as cq
import numpy as np

def cubic_unit_cell(cell_size: float, strut_diameter: float) -> cq.Workplane:
    """Generate a simple cubic unit cell.

    Args:
        cell_size: Edge length of the cubic cell (mm)
        strut_diameter: Diameter of cylindrical struts (mm)

    Returns:
        CadQuery solid of one unit cell
    """
    L = cell_size
    r = strut_diameter / 2.0
    result = cq.Workplane("XY")

    # Define the 12 edges of a cube as (start, end) coordinate pairs
    edges = [
        # Bottom face edges
        ((0, 0, 0), (L, 0, 0)),
        ((L, 0, 0), (L, L, 0)),
        ((L, L, 0), (0, L, 0)),
        ((0, L, 0), (0, 0, 0)),
        # Top face edges
        ((0, 0, L), (L, 0, L)),
        ((L, 0, L), (L, L, L)),
        ((L, L, L), (0, L, L)),
        ((0, L, L), (0, 0, L)),
        # Vertical edges
        ((0, 0, 0), (0, 0, L)),
        ((L, 0, 0), (L, 0, L)),
        ((L, L, 0), (L, L, L)),
        ((0, L, 0), (0, L, L)),
    ]

    # Build each strut as a cylinder between two points
    struts = []
    for (x1, y1, z1), (x2, y2, z2) in edges:
        mid_x = (x1 + x2) / 2
        mid_y = (y1 + y2) / 2
        mid_z = (z1 + z2) / 2
        length = np.sqrt((x2-x1)**2 + (y2-y1)**2 + (z2-z1)**2)

        # Strut direction: the cylinder is built from the first point
        # along this direction, so it follows the cube edge
        dx, dy, dz = x2 - x1, y2 - y1, z2 - z1

        strut = cq.Workplane("XY").newObject([
            cq.Solid.makeCylinder(
                r, length,
                pnt=cq.Vector(x1, y1, z1),
                dir=cq.Vector(dx, dy, dz),
            )
        ])
        struts.append(strut)

    # Union all struts together
    result = struts[0]
    for s in struts[1:]:
        result = result.union(s)

    # Add spherical nodes at corners for smooth joints
    for x in [0, L]:
        for y in [0, L]:
            for z in [0, L]:
                node = cq.Workplane("XY").newObject([
                    cq.Solid.makeSphere(r * 1.2, pnt=cq.Vector(x, y, z))
                ])
                result = result.union(node)

    return result

# Generate a 10mm cubic cell with 1mm struts
cell = cubic_unit_cell(cell_size=10.0, strut_diameter=1.0)
```

```python
import cadquery as cq
import numpy as np
from typing import Tuple

def make_strut(p1: Tuple[float, float, float],
               p2: Tuple[float, float, float],
               diameter: float) -> cq.Workplane:
    """Create a cylindrical strut between two 3D points.

    The cylinder starts at p1 and points toward p2, so it works
    for any orientation.
    """
    start = cq.Vector(*p1)
    direction = cq.Vector(*p2) - start
    length = direction.Length

    r = diameter / 2.0
    strut = cq.Workplane("XY").newObject([
        cq.Solid.makeCylinder(r, length, pnt=start, dir=direction)
    ])

    return strut

def bcc_unit_cell(cell_size: float, strut_diameter: float) -> cq.Workplane:
    """Generate a BCC unit cell.

    Eight diagonal struts connect corners to body center.
    """
    L = cell_size
    r = strut_diameter / 2.0
    center = (L/2, L/2, L/2)

    # BCC: 8 corners connected to body center
    corners = [
        (0, 0, 0), (L, 0, 0), (L, L, 0), (0, L, 0),
        (0, 0, L), (L, 0, L), (L, L, L), (0, L, L),
    ]

    struts = []
    for corner in corners:
        strut = make_strut(corner, center, strut_diameter)
        struts.append(strut)

    # Union all struts
    result = struts[0]
    for s in struts[1:]:
        result = result.union(s)

    # Add spherical nodes
    all_nodes = corners + [center]
    for node_pos in all_nodes:
        node = cq.Workplane("XY").newObject([
            cq.Solid.makeSphere(r * 1.3, pnt=cq.Vector(*node_pos))
        ])
        result = result.union(node)

    return result

# Generate a BCC cell: 10mm size, 0.8mm struts
bcc_cell = bcc_unit_cell(cell_size=10.0, strut_diameter=0.8)
```

In the octet-truss the struts form triangles, and a triangle cannot change shape unless a strut changes length. So the struts stretch, and the lattice is much stiffer than a BCC lattice of the same density.

```python
import cadquery as cq
import numpy as np

def octet_truss_unit_cell(cell_size: float,
                          strut_diameter: float) -> cq.Workplane:
    """Generate an octet-truss unit cell.

    14 nodes: 8 corners + 6 face centers
    36 struts connecting nearest neighbors
    """
    L = cell_size
    r = strut_diameter / 2.0

    # 8 corner nodes
    corners = [
        (0, 0, 0), (L, 0, 0), (L, L, 0), (0, L, 0),
        (0, 0, L), (L, 0, L), (L, L, L), (0, L, L),
    ]

    # 6 face center nodes
    face_centers = [
        (L/2, L/2, 0),   # bottom
        (L/2, L/2, L),   # top
        (L/2, 0, L/2),   # front
        (L/2, L, L/2),   # back
        (0, L/2, L/2),   # left
        (L, L/2, L/2),   # right
    ]

    all_nodes = corners + face_centers

    # Connect each face center to the 4 corners of its face
    # Plus connect face centers to each other through body diagonals
    connections = []

    # Bottom face center (index 8) to bottom corners
    connections += [(8, 0), (8, 1), (8, 2), (8, 3)]
    # Top face center (index 9) to top corners
    connections += [(9, 4), (9, 5), (9, 6), (9, 7)]
    # Front face center (index 10) to front corners
    connections += [(10, 0), (10, 1), (10, 4), (10, 5)]
    # Back face center (index 11) to back corners
    connections += [(11, 2), (11, 3), (11, 6), (11, 7)]
    # Left face center (index 12) to left corners
    connections += [(12, 0), (12, 3), (12, 4), (12, 7)]
    # Right face center (index 13) to right corners
    connections += [(13, 1), (13, 2), (13, 5), (13, 6)]

    # Cross-connections between neighbouring face centers (the inner
    # octahedron: 12 struts). Opposite faces (8-9, 10-11, 12-13) are
    # not nearest neighbours and are not connected.
    connections += [
        (8, 10), (8, 11), (8, 12), (8, 13),
        (9, 10), (9, 11), (9, 12), (9, 13),
        (10, 12), (10, 13),
        (11, 12), (11, 13),
    ]

    struts = []
    for i, j in connections:
        p1 = all_nodes[i]
        p2 = all_nodes[j]
        strut = make_strut(p1, p2, strut_diameter)
        struts.append(strut)

    # Union all struts
    result = struts[0]
    for s in struts[1:]:
        result = result.union(s)

    # Spherical joints at all nodes
    for pos in all_nodes:
        node = cq.Workplane("XY").newObject([
            cq.Solid.makeSphere(r * 1.4, pnt=cq.Vector(*pos))
        ])
        result = result.union(node)

    return result

# Octet-truss: 12mm cell, 0.6mm struts
octet = octet_truss_unit_cell(cell_size=12.0, strut_diameter=0.6)
```

### Arraying Unit Cells into a Lattice Volume

The next function places copies of one cell on a 3D grid, as separate bodies in an assembly. The example makes 64 cells in a block 32 mm wide.

```python
def array_lattice(unit_cell_func, cell_size: float,
                  strut_diameter: float,
                  nx: int, ny: int, nz: int) -> cq.Assembly:
    """Array a unit cell into an nx × ny × nz lattice block.

    Args:
        unit_cell_func: Function that returns a unit cell solid
        cell_size: Size of each unit cell (mm)
        strut_diameter: Strut diameter (mm)
        nx, ny, nz: Number of cells in each direction

    Returns:
        CadQuery Assembly of arrayed cells
    """
    assembly = cq.Assembly()

    # Generate one cell and reuse it
    cell = unit_cell_func(cell_size, strut_diameter)

    for ix in range(nx):
        for iy in range(ny):
            for iz in range(nz):
                offset = (
                    ix * cell_size,
                    iy * cell_size,
                    iz * cell_size,
                )
                assembly.add(
                    cell,
                    loc=cq.Location(cq.Vector(*offset)),
                    name=f"cell_{ix}_{iy}_{iz}",
                )

    return assembly

# Create a 4x4x4 BCC lattice block
lattice_block = array_lattice(
    bcc_unit_cell,
    cell_size=8.0,
    strut_diameter=0.8,
    nx=4, ny=4, nz=4
)
```

:::tip[Performance Tip]
Fusing a large array with boolean unions is very slow.
:::

## Triply Periodic Minimal Surfaces (TPMS)

<InArticleAd />


Struts meet at sharp joints, and stress collects there. A TPMS lattice has no joints. It is one smooth wall that repeats in all three directions (triply periodic), and at every point it bends like a saddle, up one way and down the other (minimal surface).

### TPMS Implicit Surface Equations

A TPMS is described by one function $f(x, y, z)$ that gives a number for every point in space, with $x$, $y$, $z$ in mm. The surface is where $f = t$. The number $t$ is the **threshold**, with no unit. This lesson calls a point solid when $f > t$. In all three functions $L$ is the cell size in mm, the distance after which the pattern repeats.

<Tabs>
  <TabItem label="Gyroid">

The gyroid is the most widely used TPMS in engineering.

$$
f_{\text{gyroid}}(x, y, z) = \sin\!\left(\frac{2\pi x}{L}\right)\cos\!\left(\frac{2\pi y}{L}\right) + \sin\!\left(\frac{2\pi y}{L}\right)\cos\!\left(\frac{2\pi z}{L}\right) + \sin\!\left(\frac{2\pi z}{L}\right)\cos\!\left(\frac{2\pi x}{L}\right) = t
$$

At $t = 0$ the surface divides space into two equal volumes that wind through each other.

**Key property:** A gyroid usually prints without supports, because its unsupported spans are short. It is not free of overhangs: small areas are nearly horizontal, and they grow with the cell size.

  </TabItem>
  <TabItem label="Schwarz-P (Primitive)">

The Schwarz-P (or "Primitive") surface has the simplest equation. It looks like a grid of rounded chambers joined by necks along the three axes.

$$
f_{\text{Schwarz-P}}(x, y, z) = \cos\!\left(\frac{2\pi x}{L}\right) + \cos\!\left(\frac{2\pi y}{L}\right) + \cos\!\left(\frac{2\pi z}{L}\right) = t
$$

**Key property:** Schwarz-P is stiff along a cell axis and weaker in other directions. The underside of its horizontal arms is an overhang, so it needs a small cell size or a tilted print.

  </TabItem>
  <TabItem label="Diamond">

The Schwarz-D (Diamond) surface follows the pattern of the atoms in a diamond crystal. It separates two channel networks that wind through each other and never join.

$$
f_{\text{diamond}}(x, y, z) = \cos\!\left(\frac{2\pi x}{L}\right)\cos\!\left(\frac{2\pi y}{L}\right)\cos\!\left(\frac{2\pi z}{L}\right) - \sin\!\left(\frac{2\pi x}{L}\right)\sin\!\left(\frac{2\pi y}{L}\right)\sin\!\left(\frac{2\pi z}{L}\right) = t
$$

**Key property:** The stiffness of a diamond lattice is nearly the same in every loading direction.

  </TabItem>
</Tabs>

### Relationship Between Threshold and Relative Density

A point is solid when $f > t$. When $t$ rises, fewer points pass that test, so the relative density $\bar{\rho}$ falls. The cell size $L$ does not change the density:

| TPMS Type | $t = 0$ (Relative Density) | $t = 0.5$ | $t = 1.0$ |
|-----------|---------------------------|-----------|-----------|
| Gyroid | ~50% | ~34% | ~17% |
| Schwarz-P | ~50% | ~36% | ~21% |
| Diamond | ~50% | ~21% | 0% (the function never exceeds 1) |

:::note[Sheet vs. Solid TPMS]
- **Solid TPMS**: fill one side of the surface, $f(x,y,z) > t$. Easier to generate and to print.
- **Sheet TPMS**: thicken the surface into a thin wall, $t_1 < f(x,y,z) < t_2$. Usually stiffer for the same weight.
:::

## TPMS Implementation with CadQuery and NumPy

<InArticleAd />


The equation says which points are solid, but a printer needs a surface made of triangles. First, compute $f$ at every point of a regular 3D grid (each point stands for one small cube of space, a voxel). Second, put triangles where the value changes sign between neighboring points, with a standard algorithm called marching cubes.

### Step 1: Evaluate the Implicit Function

The function returns $f - t$ at every grid point: positive in the solid, negative in the open space. The example uses 100 points over 40 mm, which is 25 points for each 10 mm cell. With far fewer, the mesh becomes rough and thin walls break up.

```python
import numpy as np
from scipy import ndimage

def evaluate_tpms(tpms_type: str,
                  bounds: tuple,
                  resolution: int,
                  period: float,
                  threshold: float = 0.0) -> np.ndarray:
    """Evaluate a TPMS implicit function on a 3D grid.

    Args:
        tpms_type: One of 'gyroid', 'schwarz_p', 'diamond'
        bounds: (xmin, xmax, ymin, ymax, zmin, zmax) in mm
        resolution: Number of voxels per axis
        period: Unit cell period L (mm)
        threshold: Level-set value t

    Returns:
        3D numpy array of function values
    """
    xmin, xmax, ymin, ymax, zmin, zmax = bounds
    x = np.linspace(xmin, xmax, resolution)
    y = np.linspace(ymin, ymax, resolution)
    z = np.linspace(zmin, zmax, resolution)
    X, Y, Z = np.meshgrid(x, y, z, indexing='ij')

    # Scale to unit cell period
    kx = 2 * np.pi * X / period
    ky = 2 * np.pi * Y / period
    kz = 2 * np.pi * Z / period

    if tpms_type == 'gyroid':
        F = (np.sin(kx) * np.cos(ky) +
             np.sin(ky) * np.cos(kz) +
             np.sin(kz) * np.cos(kx))
    elif tpms_type == 'schwarz_p':
        F = np.cos(kx) + np.cos(ky) + np.cos(kz)
    elif tpms_type == 'diamond':
        F = (np.cos(kx) * np.cos(ky) * np.cos(kz) -
             np.sin(kx) * np.sin(ky) * np.sin(kz))
    else:
        raise ValueError(f"Unknown TPMS type: {tpms_type}")

    # Return the signed field F - threshold: positive where solid, negative where empty
    return (F - threshold)

# Example: Gyroid in a 40mm cube, 10mm period
field = evaluate_tpms(
    'gyroid',
    bounds=(0, 40, 0, 40, 0, 40),
    resolution=100,
    period=10.0,
    threshold=0.0
)
```

### Step 2: Extract Isosurface with Marching Cubes

A printable mesh must be closed, or watertight. So the function first surrounds the grid with one layer of empty points, which closes the surface where the solid touches the edge of the block. After the run, `mesh.is_watertight` must be `True`.

```python
from skimage.measure import marching_cubes  # pip install scikit-image
import trimesh

def field_to_mesh(field: np.ndarray,
                  bounds: tuple,
                  level: float = 0.0) -> trimesh.Trimesh:
    """Convert a 3D scalar field to a triangle mesh.

    Args:
        field: 3D numpy array from evaluate_tpms
        bounds: Physical bounds (xmin, xmax, ymin, ymax, zmin, zmax)
        level: Isosurface level (usually 0.0)

    Returns:
        trimesh.Trimesh object
    """
    xmin, xmax, ymin, ymax, zmin, zmax = bounds
    spacing = (
        (xmax - xmin) / (field.shape[0] - 1),
        (ymax - ymin) / (field.shape[1] - 1),
        (zmax - zmin) / (field.shape[2] - 1),
    )

    # Values exactly on the level give triangles of zero area (holes
    # in the mesh), so move them a very small distance off it
    eps = 1e-4
    field = np.where(np.abs(field - level) < eps, level + eps, field)

    # Pad the field with one layer of "empty" values. Without this the
    # surface stays open where the solid touches the bounds, and the
    # mesh is not watertight (not printable, and its volume is wrong).
    padded = np.pad(field, 1, mode='constant', constant_values=level - 10.0)

    verts, faces, normals, _ = marching_cubes(
        padded, level=level, spacing=spacing
    )

    # Offset vertices to match physical bounds
    # (one voxel back because of the padding layer)
    verts[:, 0] += xmin - spacing[0]
    verts[:, 1] += ymin - spacing[1]
    verts[:, 2] += zmin - spacing[2]

    mesh = trimesh.Trimesh(vertices=verts, faces=faces)

    # Make sure the triangles face outward (positive volume)
    if mesh.volume < 0:
        mesh.invert()

    return mesh

# Extract the isosurface
mesh = field_to_mesh(field, bounds=(0, 40, 0, 40, 0, 40))
mesh.export("gyroid_40mm.stl")
print(f"Mesh: {len(mesh.vertices)} vertices, {len(mesh.faces)} faces")
```

### Step 3: Convert Mesh to CadQuery Solid (Optional)

A mesh is enough for printing. You need this step only to combine the lattice with CadQuery shapes by boolean operations (union, cut, intersect):

```python
import cadquery as cq

def stl_to_cadquery(stl_path: str) -> cq.Workplane:
    """Import an STL file as a CadQuery solid.

    Note: This requires the STL to be a valid, watertight mesh.
    Every triangle becomes one face of the solid, so this is slow
    and memory-hungry for large meshes. Test it on a small block first.
    """
    from OCP.StlAPI import StlAPI_Reader
    from OCP.TopoDS import TopoDS_Shape
    from OCP.BRepBuilderAPI import BRepBuilderAPI_Sewing

    shape = TopoDS_Shape()
    if not StlAPI_Reader().Read(shape, stl_path):
        raise IOError(f"Could not read {stl_path}")

    # Join the separate triangles into one closed shell, then a solid
    sewing = BRepBuilderAPI_Sewing(1e-6)
    sewing.Add(shape)
    sewing.Perform()
    shell = cq.Shape.cast(sewing.SewedShape())
    solid = cq.Solid.makeSolid(shell)
    return cq.Workplane("XY").add(solid)
```

### Sheet TPMS Generation

A sheet TPMS keeps the points where $f$ is close to zero, $|f| < \Delta t / 2$. The code chooses $\Delta t$ with a rough rule that assumes $f$ changes by 1 over a distance of $L / 2\pi$. On a gyroid $f$ changes about 1.5 times faster, so the wall comes out near two thirds of the request: about 0.26 mm for the 0.4 mm asked below. Measure the wall in the mesh before printing.

```python
def sheet_tpms(tpms_type: str, bounds: tuple, resolution: int,
               period: float, wall_thickness: float) -> trimesh.Trimesh:
    """Generate a sheet TPMS with defined wall thickness.

    Creates geometry where: -t/2 < f(x,y,z) < t/2

    Args:
        wall_thickness: Desired wall thickness in mm
        (other args as in evaluate_tpms)
    """
    field = evaluate_tpms(tpms_type, bounds, resolution, period,
                          threshold=0.0)

    # The threshold range maps approximately to wall thickness
    # Calibration: for gyroid with period L, threshold range dt
    # gives wall_thickness ≈ dt * L / (2*pi)
    dt = wall_thickness * 2 * np.pi / period

    # Sheet region: |f(x,y,z)| < dt/2
    sheet_field = np.abs(field) - dt / 2

    # Extract outer surface (where sheet_field = 0)
    mesh = field_to_mesh(-sheet_field, bounds)

    return mesh

# 0.4mm wall sheet gyroid
sheet = sheet_tpms(
    'gyroid',
    bounds=(0, 30, 0, 30, 0, 30),
    resolution=150,
    period=8.0,
    wall_thickness=0.4
)
sheet.export("gyroid_sheet_30mm.stl")
```

## Graded Density Lattices

<InArticleAd />


A uniform lattice has the same density everywhere, but the load in a real part is not the same everywhere. A **graded lattice** puts more material where the stress is high and less where it is low.

### Approach 1: Graded Strut Thickness

In a strut lattice, change the strut diameter from layer to layer. With 0.4 mm at the bottom and 1.2 mm at the top in 8 mm cells, the BCC formula gives a relative density from 1.4 to 12 percent.

```python
def graded_bcc_lattice(cell_size: float,
                       nx: int, ny: int, nz: int,
                       d_min: float, d_max: float,
                       gradient_axis: str = 'z') -> cq.Assembly:
    """Generate a BCC lattice with linearly graded strut diameter.

    Args:
        cell_size: Unit cell size (mm)
        nx, ny, nz: Number of cells per axis
        d_min: Minimum strut diameter (mm) at gradient start
        d_max: Maximum strut diameter (mm) at gradient end
        gradient_axis: Axis along which density varies ('x', 'y', 'z')
    """
    assembly = cq.Assembly()

    # Map axis to cell count
    n_gradient = {'x': nx, 'y': ny, 'z': nz}[gradient_axis]

    for ix in range(nx):
        for iy in range(ny):
            for iz in range(nz):
                # Compute gradient parameter (0 to 1)
                if gradient_axis == 'z':
                    t = iz / max(nz - 1, 1)
                elif gradient_axis == 'y':
                    t = iy / max(ny - 1, 1)
                else:
                    t = ix / max(nx - 1, 1)

                # Linear interpolation of strut diameter
                d = d_min + t * (d_max - d_min)

                cell = bcc_unit_cell(cell_size, d)
                offset = (
                    ix * cell_size,
                    iy * cell_size,
                    iz * cell_size
                )
                assembly.add(
                    cell,
                    loc=cq.Location(cq.Vector(*offset)),
                    name=f"cell_{ix}_{iy}_{iz}_d{d:.2f}",
                )

    return assembly

# Graded BCC: thin at bottom (0.4mm), thick at top (1.2mm)
graded = graded_bcc_lattice(
    cell_size=8.0,
    nx=5, ny=5, nz=8,
    d_min=0.4, d_max=1.2,
    gradient_axis='z'
)
```

### Approach 2: Graded TPMS Threshold

In a TPMS, let the threshold change with position: a point is solid when $f(x, y, z) > t(x, y, z)$. The example raises $t$ from 0.0 at the bottom to 0.8 at the top, so the gyroid goes from 50 percent solid to about 24 percent:

```python
def graded_tpms(tpms_type: str, bounds: tuple, resolution: int,
                period: float, t_min: float, t_max: float,
                gradient_axis: str = 'z') -> np.ndarray:
    """Evaluate TPMS with spatially varying threshold.

    Creates a density gradient: dense where t is small,
    sparse where t is large.
    """
    xmin, xmax, ymin, ymax, zmin, zmax = bounds
    x = np.linspace(xmin, xmax, resolution)
    y = np.linspace(ymin, ymax, resolution)
    z = np.linspace(zmin, zmax, resolution)
    X, Y, Z = np.meshgrid(x, y, z, indexing='ij')

    # Compute TPMS field
    kx = 2 * np.pi * X / period
    ky = 2 * np.pi * Y / period
    kz = 2 * np.pi * Z / period

    if tpms_type == 'gyroid':
        F = (np.sin(kx) * np.cos(ky) +
             np.sin(ky) * np.cos(kz) +
             np.sin(kz) * np.cos(kx))
    elif tpms_type == 'schwarz_p':
        F = np.cos(kx) + np.cos(ky) + np.cos(kz)
    else:
        raise ValueError(f"Unknown type: {tpms_type}")

    # Spatially varying threshold
    if gradient_axis == 'z':
        # Normalize Z to [0, 1] range
        T = t_min + (t_max - t_min) * (Z - zmin) / (zmax - zmin)
    elif gradient_axis == 'y':
        T = t_min + (t_max - t_min) * (Y - ymin) / (ymax - ymin)
    else:
        T = t_min + (t_max - t_min) * (X - xmin) / (xmax - xmin)

    return F - T

# Dense at bottom (t=0.0), sparse at top (t=0.8)
graded_field = graded_tpms(
    'gyroid',
    bounds=(0, 40, 0, 40, 0, 60),
    resolution=120,
    period=8.0,
    t_min=0.0, t_max=0.8,
    gradient_axis='z'
)

graded_mesh = field_to_mesh(graded_field, (0, 40, 0, 40, 0, 60))
graded_mesh.export("gyroid_graded.stl")
```

:::caution[Gradient Continuity]
A sudden step in density concentrates stress at the step. Change the density gradually, with a straight-line gradient as here or a smoother curve.
:::

## Conformal Lattice Filling

<InArticleAd />


A **conformal lattice** fills the inside of a part of any shape, such as a bracket, and keeps a solid outer skin, so the part still has smooth faces.

<Steps>
1. **Define the outer envelope**: your part geometry in CadQuery

2. **Generate the lattice** in a bounding box that encloses the part

3. **Boolean intersection**: cut the lattice to the part boundary

4. **Shell the part** (optional): create a solid skin around the lattice interior
</Steps>

```python
import cadquery as cq

def conformal_lattice_fill(
    envelope: cq.Workplane,
    lattice_stl_path: str,
    shell_thickness: float = 1.0
) -> cq.Workplane:
    """Fill an arbitrary shape with lattice structure.

    Args:
        envelope: CadQuery solid defining the outer boundary
        lattice_stl_path: Path to STL of the lattice block
        shell_thickness: Thickness of solid outer skin (mm)

    Returns:
        CadQuery solid: shell + internal lattice
    """
    # Create outer shell
    shell = envelope.shell(-shell_thickness)

    # Import lattice mesh (see stl_to_cadquery above)
    lattice_wp = stl_to_cadquery(lattice_stl_path)

    # Boolean intersection: trim lattice to inner volume
    inner_volume = envelope.cut(shell)
    lattice_trimmed = lattice_wp.intersect(inner_volume)

    # Combine shell + trimmed lattice
    result = shell.union(lattice_trimmed)

    return result

# Example: Cylindrical part filled with gyroid
cylinder = (
    cq.Workplane("XY")
    .cylinder(50, 20)  # 50mm tall, 20mm radius
)
```

### Alternative: Direct Voxel Intersection

Boolean operations on a large mesh are slow and often fail. A more robust way stays on the voxel grid. For every grid point, compute its **signed distance** to the surface of the part: the distance in mm, with one sign inside and the other outside. A point is solid if it lies in the skin, or deeper inside and on the solid side of the TPMS.

:::caution[Check the sign first]
The code below expects negative distances inside the part. The trimesh documentation states the opposite for `signed_distance`: positive inside. Print `sdf` for a point that you know is inside. If it is positive, put a minus sign in front of the `signed_distance(...)` call, or the lattice is built outside the part.
:::

```python
def conformal_tpms_direct(
    tpms_type: str,
    envelope_stl: str,
    bounds: tuple,
    resolution: int,
    period: float,
    threshold: float,
    shell_thickness: float
) -> trimesh.Trimesh:
    """Generate conformal TPMS by voxel-level intersection.

    More robust than boolean operations for complex geometries.
    """
    import trimesh

    # Load envelope mesh and compute signed distance field
    envelope = trimesh.load(envelope_stl)

    xmin, xmax, ymin, ymax, zmin, zmax = bounds
    x = np.linspace(xmin, xmax, resolution)
    y = np.linspace(ymin, ymax, resolution)
    z = np.linspace(zmin, zmax, resolution)
    X, Y, Z = np.meshgrid(x, y, z, indexing='ij')

    # Flatten grid points for proximity query
    points = np.column_stack([X.ravel(), Y.ravel(), Z.ravel()])

    # Signed distance: negative inside, positive outside
    sdf = trimesh.proximity.signed_distance(envelope, points)
    sdf = sdf.reshape(X.shape)

    # Evaluate TPMS field
    tpms_field = evaluate_tpms(
        tpms_type, bounds, resolution, period, threshold
    )

    # Combine: TPMS only where inside the envelope
    # Shell region: -shell_thickness < sdf < 0
    # Lattice region: sdf < -shell_thickness AND tpms_field > 0
    shell_mask = (sdf < 0) & (sdf > -shell_thickness)
    lattice_mask = (sdf < -shell_thickness) & (tpms_field > 0)

    combined = np.zeros_like(sdf)
    combined[shell_mask] = 1.0
    combined[lattice_mask] = 1.0

    mesh = field_to_mesh(combined - 0.5, bounds)
    return mesh
```

## Printability Constraints

<InArticleAd />


A lattice that is correct on the screen can still fail in the printer. Each process has a smallest feature it can make and its own way of holding up material that hangs in the air.
<Tabs>
  <TabItem label="FDM Constraints">

**Fused Deposition Modeling** (FDM) lays down a melted plastic thread through a nozzle. It is the most limiting process for lattices.

<CardGrid>
  <Card title="Minimum Strut Diameter" icon="warning">
    1.0 to 2.0 mm. Thinner struts do not form or break at a touch. Rule: at least 2.5 times the nozzle diameter.
  </Card>

  <Card title="Overhang Angle" icon="warning">
    A wall may lean up to about 45 degrees from vertical with no support under it. BCC struts lean 54.7 degrees, so they print only when short.
  </Card>

  <Card title="Minimum Wall Thickness" icon="warning">
    0.8 to 1.2 mm for sheet TPMS walls: at least two nozzle widths.
  </Card>

  <Card title="Cell Size" icon="warning">
    At least 5 mm with a 0.4 mm nozzle. In smaller cells the nozzle cannot follow the shape.
  </Card>
</CardGrid>

  </TabItem>
  <TabItem label="SLA Constraints">

**Stereolithography** (SLA) hardens liquid resin with light, layer by layer. It makes much finer features than FDM.

<CardGrid>
  <Card title="Minimum Strut Diameter" icon="approve-check">
    0.3 to 0.5 mm, depending on the resin and the layer height.
  </Card>

  <Card title="Drainage Holes" icon="warning">
    Liquid resin must be able to run out. A closed cavity needs a drain hole of at least 1.5 mm. TPMS lattices are open everywhere, which helps.
  </Card>

  <Card title="Support Removal" icon="warning">
    Supports inside a dense lattice cannot be cut out. Choose a lattice and a print direction that need no supports inside.
  </Card>
</CardGrid>

  </TabItem>
  <TabItem label="SLS/MJF Constraints">

**Selective Laser Sintering** (SLS) and **Multi Jet Fusion** (MJF) fuse a bed of powder, layer by layer. The loose powder holds the part up, so no supports are needed. These are the best processes for lattices.

<CardGrid>
  <Card title="Minimum Strut Diameter" icon="approve-check">
    0.5 to 0.8 mm in nylon PA12. Metal powder machines reach 0.3 to 0.5 mm.
  </Card>

  <Card title="Powder Removal" icon="warning">
    Powder trapped in a closed cell stays there. Every cell must open to the outside, through openings of at least 1.0 mm for PA12 and 0.5 mm for metals.
  </Card>

  <Card title="Cell Size" icon="approve-check">
    2 to 3 mm in PA12 and about 1.5 mm in metal. Confirm with a test piece.
  </Card>
</CardGrid>

  </TabItem>
</Tabs>

### Printability Validation Checklist

<Steps>
1. **Smallest feature**: every strut and wall is thicker than the process minimum

2. **Overhangs**: for FDM and SLA, the steepest overhang is within the limit

3. **Drainage**: every channel opens to the outside, so powder or resin can leave

4. **Slender struts**: a strut more than 10 times longer than its diameter warps and breaks easily

5. **Test coupon**: print a sample of 2x2x2 cells before the full part
</Steps>

The function below checks that the mesh is watertight and finds the steepest downward-facing triangle. It does not measure strut or wall thickness: it only returns the limits for the process.

Every TPMS has some triangles that are nearly horizontal. For a gyroid the function reports almost 90 degrees and `overhang_ok: False` on FDM, although only about a quarter of the downward-facing area is steeper than 45 degrees. Treat a failed result as a reason to print a test coupon.

```python
def validate_lattice_printability(
    mesh: trimesh.Trimesh,
    process: str = 'fdm',
    nozzle_diameter: float = 0.4
) -> dict:
    """Check a lattice mesh against printability constraints.

    Args:
        mesh: Trimesh of the lattice structure
        process: 'fdm', 'sla', or 'sls'
        nozzle_diameter: FDM nozzle diameter (mm)

    Returns:
        Dictionary of check results
    """
    constraints = {
        'fdm': {
            'min_feature': 2.5 * nozzle_diameter,
            'max_overhang_deg': 45,
            'min_wall': 2 * nozzle_diameter,
        },
        'sla': {
            'min_feature': 0.4,
            'max_overhang_deg': 30,  # conservative for unsupported
            'min_wall': 0.3,
        },
        'sls': {
            'min_feature': 0.5,
            'max_overhang_deg': 90,  # self-supporting
            'min_wall': 0.5,
        },
    }

    c = constraints[process]

    # Check overhang angles from face normals.
    # Only faces that look downward (normal z < 0) are overhangs.
    # Angle from vertical: 0 for a vertical wall, 90 for a flat ceiling.
    normals = mesh.face_normals
    z_component = normals[:, 2]  # vertical component
    downward = z_component < 0
    if downward.any():
        overhang_angles = np.degrees(np.arcsin(np.clip(
            -z_component[downward], 0, 1
        )))
        max_overhang = np.max(overhang_angles)
    else:
        max_overhang = 0.0

    # Check if mesh is watertight (required for all processes)
    is_watertight = mesh.is_watertight

    results = {
        'process': process,
        'is_watertight': is_watertight,
        'max_overhang_deg': float(max_overhang),
        'overhang_ok': max_overhang <= c['max_overhang_deg'],
        'min_feature_mm': c['min_feature'],
        'min_wall_mm': c['min_wall'],
    }

    return results
```

## Applications

<InArticleAd />


- **Light structures**: lattice-filled aircraft brackets and panels, such as the Airbus "bionic partition" cabin wall.
- **Bone implants**: a porous titanium lattice can be made about as stiff as bone, and bone grows into its pores.
- **Energy absorption**: a lattice crushes cell by cell at a nearly steady force, which suits helmets and packaging.

## Complete Example: Graded Gyroid-Filled Cylinder

<InArticleAd />


This example builds a cylinder 30 mm in diameter and 50 mm tall, with a solid skin of 1.5 mm, solid end caps, and a gyroid inside that goes from 50 percent solid at the bottom to about 30 percent at the top.

In the output, the relative density should be near 54 percent. The skin and the caps alone are 24 percent of the solid cylinder, so in a small part the skin limits what a lattice can save.

```python
import numpy as np
from skimage.measure import marching_cubes
import trimesh

# === Parameters ===
outer_radius = 15.0     # mm
height = 50.0           # mm
shell_thickness = 1.5   # mm solid outer wall
period = 6.0            # mm gyroid cell period
t_bottom = 0.0          # dense at bottom (load-bearing end)
t_top = 0.6             # sparse at top (weight savings)
resolution = 200        # voxels per axis

# === Build coordinate grid ===
bounds = (-outer_radius, outer_radius,
          -outer_radius, outer_radius,
          0, height)
xmin, xmax, ymin, ymax, zmin, zmax = bounds
x = np.linspace(xmin, xmax, resolution)
y = np.linspace(ymin, ymax, resolution)
z = np.linspace(zmin, zmax, resolution)
X, Y, Z = np.meshgrid(x, y, z, indexing='ij')

# === Cylindrical signed distance field ===
R = np.sqrt(X**2 + Y**2)
# Negative inside cylinder, positive outside
sdf_outer = R - outer_radius
sdf_inner = R - (outer_radius - shell_thickness)

# === Graded gyroid field ===
kx = 2 * np.pi * X / period
ky = 2 * np.pi * Y / period
kz = 2 * np.pi * Z / period
F_gyroid = (np.sin(kx) * np.cos(ky) +
            np.sin(ky) * np.cos(kz) +
            np.sin(kz) * np.cos(kx))

# Spatially varying threshold (linear gradient along Z)
T = t_bottom + (t_top - t_bottom) * (Z - zmin) / (zmax - zmin)

# === Combine: shell + graded lattice interior ===
# Shell region: inside outer cylinder, outside inner cylinder
shell_mask = (sdf_outer < 0) & (sdf_inner > 0)
# Lattice region: inside inner cylinder AND gyroid > threshold
lattice_mask = (sdf_inner < 0) & (F_gyroid > T)
# Top and bottom caps (solid)
cap_mask = (sdf_outer < 0) & ((Z < zmin + shell_thickness) |
                                (Z > zmax - shell_thickness))

combined = np.zeros_like(R, dtype=float)
combined[shell_mask] = 1.0
combined[lattice_mask] = 1.0
combined[cap_mask] = 1.0

# === Extract isosurface ===
spacing = (
    (xmax - xmin) / (resolution - 1),
    (ymax - ymin) / (resolution - 1),
    (zmax - zmin) / (resolution - 1),
)
# Pad with one empty layer so the surface is closed at the bounds
# (the end caps touch zmin and zmax)
combined = np.pad(combined, 1, mode='constant', constant_values=0.0)
verts, faces, normals, _ = marching_cubes(combined, level=0.5,
                                           spacing=spacing)
verts[:, 0] += xmin - spacing[0]
verts[:, 1] += ymin - spacing[1]
verts[:, 2] += zmin - spacing[2]

mesh = trimesh.Trimesh(vertices=verts, faces=faces)

# Make sure the triangles face outward (positive volume)
if mesh.volume < 0:
    mesh.invert()

# === Report ===
solid_volume = np.pi * outer_radius**2 * height
lattice_volume = mesh.volume
relative_density = lattice_volume / solid_volume

print(f"Solid cylinder volume:  {solid_volume:.1f} mm³")
print(f"Lattice part volume:    {lattice_volume:.1f} mm³")
print(f"Relative density:       {relative_density:.1%}")
print(f"Weight savings:         {1 - relative_density:.1%}")

# Export
mesh.export("graded_gyroid_cylinder.stl")
print("Exported: graded_gyroid_cylinder.stl")
```
